## 1. ขอบเขตต้นแบบ
- เล่นเดี่ยว ไม่มีเซิร์ฟเวอร์
- โค้ดแยก **สถานะคดี** กับ **การรับรู้ของผู้เล่น** ตั้งแต่ต้น เพื่อรองรับการเล่นเป็นทีมภายหลัง
- เล่นบน **มือถือ แนวตั้ง สัมผัสหน้าจอ** ไม่ใช่ VR/AR
- "แว่น AR" เป็นเพียงแรงบันดาลใจด้านภาพของมุมมองบุคคลที่หนึ่งและ HUD เท่านั้น ไม่ใช่อุปกรณ์หรือตัวละครในเกม — ในเกมคือ **HUD บนหน้าจอ (สไตล์ได้แรงบันดาลใจจากแว่น AR)**

## 1.0 กลุ่มผู้เล่น
- **ทุกวัย** เน้นครอบครัวเล่นด้วยกัน โดย **แต่ละคนใช้มือถือของตัวเอง** และเล่นจากมุมมองบุคคลที่หนึ่งของตัวเอง (สอดคล้องกับสเปก v0.3: ข้อเท็จจริงของคดีใช้ร่วมกัน แต่สิ่งที่ผู้เล่นแต่ละคนรู้แยกกัน) ต้นแบบแรกยังเล่นเดี่ยวบนเครื่องเดียว (การเล่นหลายเครื่องเป็นแผนของเวอร์ชันถัดไป)
- **ผลต่อการออกแบบ:**
  - ภาษาไทยง่าย ประโยคสั้น
  - มีปุ่มเปิด/ปิด **เสียงพากย์** อ่านบทสนทนาและเบาะแส สำหรับเด็กเล็กที่ยังอ่านไม่คล่อง (ไม่บังคับ)
  - ปรับขนาดตัวอักษรได้
  - ระดับความยาก (ง่าย / ปานกลาง / ยาก) รองรับสมาชิกครอบครัวต่างวัย

## 1.1 การเริ่มเกม
- (ค่าตั้งต้น ผู้ใช้ปรับได้) เกมเปิดที่ห้องของผู้เล่น
- บทสอนสั้น 3 ขั้นผ่าน HUD: (1) แตะวัตถุ (2) ปุ่มย้อนกลับ (3) เปิดสมุด/กระดานคดี
- เลือกระดับความยาก (ง่าย / ปานกลาง / ยาก) ทุกครั้งที่เริ่มคดี ตอนออกจากประตูห้อง ระดับที่เลือกกำหนดเวลาเป้าหมายสำหรับ 3 ดาว ตัวเลือกแสดงเฉพาะชื่อระดับ ไม่แสดงเวลา

## 2. สไตล์ภาพ — แบบ B
3 มิติ low-poly สีพาสเทลแบบของเล่น + HUD บนหน้าจอ (สไตล์ได้แรงบันดาลใจจากแว่น AR) เส้นสีฟ้า ป้ายชี้วัตถุ ปุ่มใหญ่ด้านล่าง

## 3. มุมมองและกล้อง
- มุมมองบุคคลที่หนึ่ง จุดกล้องตายตัว ไม่เดินอิสระ
- แต่ละห้องมี **มุมกว้าง 1 มุม มองจากประตู**
- แตะคน/วัตถุ → **ตัดภาพเฟดสั้น ๆ** เข้ามุมใกล้หรือเปิดมินิเกม
- **ปุ่มย้อนกลับใหญ่ มุมล่างซ้าย** เสมอ
- เปลี่ยนห้องด้วยจุดแตะที่ประตู หรือแตะห้องบนแผนผังบ้าน (เฟดเช่นกัน)

## 4. ลำดับการเล่นหลัก

```text
ห้องของผู้เล่น (hub) → เดินทางเยี่ยมบ้านย่า → ไขคดี → กลับบ้านพร้อมของรางวัล → ประตูคดีถัดไป
```

## 4.0 หน้าเลือกเหตุการณ์และฉากการ์ตูนเปิดเรื่อง (ตัดสินใจแล้ว)
- **ออกจากห้อง:** แตะประตูในห้องของผู้เล่น → หน้า **"เลือกเหตุการณ์"** (ไม่เข้าคดีโดยตรง)
- หน้าเลือกเหตุการณ์ = รายการการ์ดเลื่อนแนวตั้ง การ์ดละ 1 เหตุการณ์ (ภาพปก ชื่อ คำโปรย) ป้าย "ใหม่" หรือ "✓ ไขแล้ว · เล่นซ้ำได้"
- เหตุการณ์ที่ยังล็อก = ภาพปกเป็นเงาสีเข้ม + 🔒 + ชื่อ "???" + เงื่อนไข เช่น "ปลดล็อกเมื่อจบคดี 01" (แบบเดียวกับมุมฝึกเล่น) แตะแล้วขึ้นข้อความเงื่อนไขเท่านั้น
- ปุ่ม ← กลับห้อง รายการสร้างจากข้อมูล `event` ของแต่ละ Story Pack — เพิ่มคดีใหม่ การ์ดขึ้นเอง
- **ฉากการ์ตูนเปิดเรื่อง (cutscene):** แตะเหตุการณ์ที่เปิดอยู่ → การ์ตูน 2–3 หน้า (ภาพแนวตั้ง 3 ช่องต่อหน้า ภาพไม่มีตัวหนังสือ) คำบรรยายและบอลลูนคำพูดเป็นข้อความ HTML ซ้อนบนภาพ (ปรับขนาดตัวอักษรและอ่าน TTS ได้ แปลภาษาได้)
- แตะ/ปัดซ้ายเพื่อไปหน้าถัดไป ปัดขวาย้อนหน้า มีจุดบอกหน้า และปุ่ม "ข้าม" ตลอดเวลา หน้าสุดท้ายแตะแล้วไปเลือกความยาก → แผนผังบ้าน
- คดี 01: หน้า 1 ยายโทรมา ครอบครัวนัดไปเยี่ยม · หน้า 2 ถึงบ้านไม้ ยายต้อนรับ · หน้า 3 ยายกังวล อัลบั้มหายจากชั้น
- ลำดับรวม: ห้องของฉัน → เลือกเหตุการณ์ → การ์ตูนเปิดเรื่อง → เลือกความยาก → แผนผังบ้าน → ห้องนั่งเล่น

## 4.0b ปฏิทินในห้อง (ตัดสินใจแล้ว)
- **ปฏิทิน (วัน) และนาฬิกา (ชั่วโมง)** เป็นวัตถุจริงในฉาก (low-poly) ผู้เล่นต้องแตะจุดเล็กบนวัตถุก่อน UI จึงเปิด
- แต่ละห้องกำหนด `calendar.purpose` เองใน Story Pack: ห้องของผู้เล่น = `upcoming` (เหตุการณ์/คดีที่จะมา ฝึกเล่นประจำวัน รางวัล) · บ้านยาย = `clue` (วันที่สำคัญเป็นเบาะแส เช่น วงแดง "บ่ายนี้ รินมาช่วยเก็บกวาดบ้าน" และวันครบรอบแต่งงานของตายาย)
- หน้าตาปฏิทินเลือกได้ด้วย `theme` (สี กรอบ ลายกระดาษ ฟอนต์ ภาพหัว) ตัวอย่าง 3 ธีม: ห้องเด็ก (ผู้เล่น) · บ้านไม้ (ยาย) · ท้องฟ้ายามค่ำ (ของตกแต่งปลดล็อกเมื่อจบคดี 01) ห้องของผู้เล่นมีแถบสลับธีมเพื่อดูตัวอย่าง

## 4.0c กลไกควบคุมเวลา (ตัดสินใจแล้ว)
- **พลังของตัวละครผู้เล่น = ควบคุมเวลา** เรื่องไม่ได้เกิดที่เวลาเดียว ผู้เล่นย้อน/เลื่อนเวลาได้แบบเกมย้อนเวลา
- แตะปฏิทินเพื่อเปลี่ยน "วัน" แตะนาฬิกาเพื่อเปลี่ยน "ชั่วโมง" เปลี่ยนแล้วสภาพห้องเปลี่ยน (ของโผล่ หาย หรือย้าย แสงเปลี่ยน) ด้วยการเฟด 300 ms ไม่มีแอนิเมชันวนซ้ำ
- กติกา: ทุกคดีเริ่มด้วยช่วงเวลาเดียว ("ตอนนี้") ช่วงเวลาอื่นปลดล็อกเมื่อพบหลักฐานที่กำหนด (`unlockBy`) ช่วงที่ยังล็อกแสดงเป็นแถบสีเข้ม "???" + คำใบ้
- ช่วงเวลาในอดีตเป็นภาพความจำของห้อง: ดูและแตะวัตถุได้ ตัวละครที่อยู่ ณ เวลานั้นปรากฏและพูดสั้น ๆ ได้เฉพาะสิ่งที่กำลังทำ (ไม่เฉลยคำตอบ) และไม่เปลี่ยนคำตอบของคดี
- คดี 01 (ห้องนั่งเล่น): **ตอนนี้ 17:00** อัลบั้มหาย โต๊ะเปียก มีข้อความของน้าริน · **บ่ายนี้ 14:00** (ปลดล็อกด้วย E02 โต๊ะเปียก) น้ารินกำลังเช็ดน้ำ แจกันล้ม น้ำนองโต๊ะ อัลบั้มยังวางบนโต๊ะ ยังไม่มีข้อความ · **เมื่อวานเย็น** (ปลดล็อกด้วย E01 ข้อความของน้าริน) ยายมะลิยืนข้างชั้น อัลบั้มตั้งอยู่บนชั้นบน ถาดชิ้นแผนผังยังอยู่ โต๊ะแห้ง — สอดคล้องกับความจริงเดิม: ยายหยิบอัลบั้มลงมาดูบนโต๊ะเมื่อเช้า น้ารินทำน้ำหกตอนเก็บกวาดบ่ายนี้ จึงย้ายอัลบั้มไปเก็บตามผังเดิมในกล่องรูปดาวใต้หน้าต่างห้องทำงาน (ผู้ย้าย เหตุผล และคำตอบสรุปคดีไม่เปลี่ยน)

### 4.1 ห้องของผู้เล่น (hub)
- เกมเปิดที่นี่ และกลับมาที่นี่หลังจบคดี
- ช่องวางของตกแต่งตายตัว **6–8 ช่อง** (ผนัง ชั้น โต๊ะ พื้น ฯลฯ) แตะช่องเพื่อวาง/สลับของ
- ของตกแต่งได้จากการไขคดีและงานเสริม (เช่น ครอสเวิร์ดของลุงเมฆ) และจากดาวรวม
- ชั้นของที่ระลึกจากคดี (โปสการ์ด รูปจากอัลบั้ม) / กระดานคดีที่ไขแล้ว / ประตูไปคดีถัดไป

### 4.2 บ้านย่า (คดี 01)

| ห้อง | สิ่งสำคัญ |
|---|---|
| ห้องนั่งเล่น (จุดเริ่ม) | ยายมะลิ · ลุงเมฆ + ครอสเวิร์ด (เสริม) · โต๊ะกลาง: รอยน้ำ ข้อความน้าริน (E01, E02) · ถาดจิ๊กซอว์แผนผังบ้าน (E04) · กล่องรูปดาวหลอกข้างโซฟา · ฉากเฉลยและโปสการ์ด |
| ห้องทำงาน | กล่องรูปดาวสีน้ำเงิน **ใต้หน้าต่าง** (เป้าหมาย) + กล่องรูปใบไม้ · ตัวล็อกเลื่อนบล็อกบนฝา → พบอัลบั้ม (E05) |
| ครัว (เสริม) | ผ้าเปียกและแจกันเติมน้ำ ยืนยัน E02 ไม่บังคับ |

**ความจริงของคดี:** น้ารินย้ายอัลบั้มเพราะน้ำหกบนโต๊ะ เก็บในกล่องรูปดาวใต้หน้าต่างในห้องทำงานตามผังเก็บของเดิม ไม่มีคนร้าย โปสการ์ด "ห้องสมุดวันวาน — ลิ้นชักหมายเลข 7" เป็นปมตอนถัดไป

## 5. ตัวละคร — ยายมะลิ
อบอุ่น ชอบเล่าเรื่องเก่า ไม่ขี้ลืมจนบดบังเบาะแส เป็นผู้เปิดคดีและให้กำลังใจ ไม่ใช่ผู้ต้องสงสัย คำใบ้แบบอ้อม ไม่บอกคำตอบ

| จังหวะ | บทพูด |
|---|---|
| เปิดคดี | "หลานมาแล้วเหรอจ๊ะ ยายหาอัลบั้มรูปครอบครัวไม่เจอ ในนั้นมีรูปตาตอนหนุ่ม ๆ ด้วยนะ" |
| ถูกถาม | "เมื่อเช้ายายยังเห็นวางอยู่บนโต๊ะกลางเลย แต่บ่ายนี้น้ารินเข้ามาเก็บกวาดนะ" |
| ผู้เล่นติด | "รูปเก่า ๆ บ้านนี้เขาเก็บไว้ที่เดียวกันมาตลอดแหละ ลองต่อแผนที่ที่หล่นกระจายอยู่ดูสิ" |
| ไขคดีได้ | "นี่ไงรูปตา ขอบใจนะหลาน มานั่งดูด้วยกันมา ยายจะเล่าให้ฟัง" |

บทเหล่านี้เสริมบทในไฟล์คดี 01 หากขัดกันให้ยึดไฟล์คดี ตัวละครอื่น: ลุงเมฆ (ครอสเวิร์ด เห็นกล่องรูปดาว) น้าริน (ย้ายอัลบั้ม กลับมาตอนเฉลย)

## 6. มินิเกม (3 แม่แบบ)
| มินิเกม | ในคดี 01 | หมายเหตุ |
|---|---|---|
| ครอสเวิร์ด | งานเสริมของลุงเมฆ | เลือกคำ/ตัวอักษรจากปุ่ม ไม่บังคับคีย์บอร์ด |
| จิ๊กซอว์ | แผนผังบ้านมุมบน (เส้นหมึกบนกระดาษครีม) | ไม่วาดรูปดาวบนแผนผัง วาดเวกเตอร์ให้ตรงฉาก 3 มิติ |
| เลื่อนบล็อก | ตัวล็อกบนฝากล่องรูปดาว | กุญแจเป็นชิ้นหนึ่งในถาด ทางออกด้านข้างไปรูกุญแจ |

ทุกแบบมีบทฝึกเดี่ยว คำใบ้แบบขั้น และเล่นซ้ำจากคลังได้

## 7. ความชำนาญ
- มินิเกมแต่ละแบบ (ครอสเวิร์ด จิ๊กซอว์ เลื่อนบล็อก) มีความชำนาญแยกกัน แสดงเป็นดาว 1–3 ดวงต่อการเล่นหนึ่งครั้ง
  - เล่นจบ = 1 ดาว
  - เล่นจบโดยใช้คำใบ้ไม่เกิน 1 ครั้ง (เวลาเท่าไรก็ได้) = 2 ดาว
  - เล่นจบโดยไม่ใช้คำใบ้ **และ** ภายในเวลาเป้าหมาย = 3 ดาว
- เวลาเป้าหมายขึ้นกับระดับความยากที่ผู้เล่นเลือกทุกครั้งที่เริ่มคดี (ตอนออกจากประตูห้อง) (ง่าย / ปกติ / ยาก)
- เกินเวลาเป้าหมายไม่ทำให้แพ้ ได้สูงสุด 2 ดาว
- ระหว่างเล่นแสดงเฉพาะเวลาที่ใช้และสถิติดีที่สุดของตัวเอง **ไม่แสดงเวลาเป้าหมาย** (ซ่อนไว้ ใช้ภายในเพื่อตัดสิน 3 ดาวเท่านั้น) ตัวแสดงดาวขณะเล่นแสดงได้ แต่ต้องไม่เผยเวลาเป้าหมาย
- เก็บผลที่ดีที่สุดไว้ ดาวรวมใช้ปลดล็อกของตกแต่งห้องส่วนตัว
- ไม่มีบทลงโทษ

**เวลาเป้าหมายเริ่มต้น (สำหรับ 3 ดาว) — สำหรับทีมออกแบบเท่านั้น ซ่อนจากผู้เล่น** — ผู้เล่นเลือกระดับความยากทุกครั้งที่เริ่มคดี

| มินิเกม | ง่าย | ปานกลาง | ยาก |
|---|---|---|---|
| ครอสเวิร์ด | 6 นาที | 4 นาที | 3 นาที |
| จิ๊กซอว์ | 4 นาที | 3 นาที | 2 นาที |
| เลื่อนบล็อก | 3 นาที | 2 นาที | 1.5 นาที |

> ค่าเริ่มต้นเท่านั้น ต้องปรับจากการทดลองเล่น

## 7.1 การสรุปคดี (กระดานคดี)

- เมื่อเก็บหลักฐานครบพอ (E01, E02, E04) กระดานคดีเปิดปุ่ม **สรุปคดี** พร้อมคำถาม 3 ข้อ
- แต่ละข้อต้องเลือกคำตอบ **และ** เลือกการ์ดหลักฐาน 1 ใบมายืนยัน (ต้นแบบใช้แตะเลือกแทนการลาก)

| ข้อ | คำถาม | วิธีตอบ | คำตอบ | หลักฐานที่รับ |
|---|---|---|---|---|
| 1 | ใครย้ายอัลบั้ม? | เลือกรูป: ยายมะลิ / ลุงเมฆ / น้าริน | น้าริน | `E01` ข้อความของน้าริน (รับ `E03` คำบอกเล่าลุงเมฆ ได้ด้วย) |
| 2 | ย้ายทำไม? | เลือก: น้ำหกบนโต๊ะ / แอบซ่อนไว้ / หยิบไปดูรูป | น้ำหกบนโต๊ะ | `E02` โต๊ะที่เปียก (ผ้าเปียกในครัวยืนยัน `E02`) |
| 3 | เก็บไว้ที่ไหน? | แตะตำแหน่งบนแผนผังบ้าน | ห้องทำงาน ใต้หน้าต่าง | `E04` แผนผังบ้าน: ภาพถ่ายเก็บใต้หน้าต่างห้องทำงาน |

- ตอบผิด (คำตอบหรือหลักฐาน): ไม่มีบทลงโทษ ยายมะลิให้คำใบ้อ้อม ๆ (ร่างบทพูด รออนุมัติ):
  - ข้อ 1: "ลองอ่านกระดาษบนโต๊ะอีกทีสิจ๊ะ ใครเป็นคนเขียนไว้นะ"
  - ข้อ 2: "โต๊ะยังเปียกอยู่เลยนะ หลานว่าเกิดอะไรขึ้น"
  - ข้อ 3: "รูปเก่า ๆ บ้านนี้เขาเก็บไว้ที่เดียวกันมาตลอดแหละ ลองต่อแผนที่ที่หล่นกระจายอยู่ดูสิ" (บทที่อนุมัติแล้ว)
  - หลักฐานไม่ตรง (บอกเลขข้อในป๊อปอัปด้วย):
    - ข้อ 1: "หลักฐานใบนี้ยังไม่ได้บอกว่าใครย้ายอัลบั้มนะ ลองหาใบที่บอกชื่อคนย้ายดู"
    - ข้อ 2: "หลักฐานใบนี้ยังไม่ได้บอกว่าทำไมต้องย้ายนะ ลองหาใบที่เกี่ยวกับโต๊ะดู"
    - ข้อ 3: "หลักฐานใบนี้ยังไม่ได้บอกว่ารูปถ่ายเก็บไว้ห้องไหนนะ ลองหาใบที่บอกที่เก็บรูปดู"
- ถูกครบ 3 ข้อ → ปลดล็อกการเปิดกล่องในห้องทำงาน (เลื่อนบล็อก) → พบอัลบั้ม (`E05`)
- การเลือกระหว่างกล่องรูปดาว/กล่องรูปใบไม้ในห้องทำงาน ยังใช้ `E03` (สัญลักษณ์รูปดาว) ตามฉาก 4 ของไฟล์คดี

## 7.2 ระบบคำใบ้

- คำใบ้มาจาก **ปุ่มคำใบ้บนหน้าจอ (รูปหลอดไฟ)** มี 3 ระดับ:
  1. บอกว่าควรไปดูที่ห้องไหน
  2. ไฮไลต์วัตถุที่ควรแตะ
  3. (เฉพาะมินิเกม) เผยขั้นที่ถูกต้อง 1 ขั้น (เช่น เติมตัวอักษร 1 ช่อง วางชิ้นจิ๊กซอว์ 1 ชิ้น เลื่อนบล็อกที่ถูก 1 ครั้ง)
- ยายมะลิให้คำใบ้ **เฉพาะหลังตอบผิดบนกระดานสรุปคดี** เท่านั้น (บทพูด "ผู้เล่นติด" ที่อนุมัติไว้ใช้เป็นคำใบ้ของยายเมื่อตอบข้อ 3 "เก็บไว้ที่ไหน" ผิด)
- เฉพาะคำใบ้ที่ใช้ **ในมินิเกม** เท่านั้นที่มีผลต่อดาวของมินิเกมนั้น คำใบ้สำรวจนอกมินิเกม (ระดับ 1–2) และคำใบ้ของยายบนกระดานสรุปคดี **ใช้ได้ฟรี ไม่มีผลต่อดาวใด ๆ** ไม่มีดาวระดับคดี (ยืนยันแล้ว)
- ปุ่มคำใบ้รูปหลอดไฟ อยู่ใกล้ HUD ด้านบน ไม่ใช่มุมล่างซ้าย (ที่ของปุ่มย้อนกลับ)

## 7.3 เสียง
- ดนตรีพื้นหลัง: นุ่ม อบอุ่น บรรยากาศบ้านชนบท
- เสียงประกอบสั้น ๆ: แตะวัตถุ พบหลักฐาน ได้ดาว
- เสียงพากย์บทสนทนา (และเบาะแส): ต้นแบบแรกใช้ **Thai TTS** เปิด/ปิดได้ อาจใช้นักพากย์จริงภายหลัง

## 7.4 การบันทึกและความคืบหน้า
- **ต้นแบบแรก:** เล่นเดี่ยว **ไม่มีบัญชี** บันทึกความคืบหน้าอัตโนมัติ **ในเครื่อง** เมื่อ: พบหลักฐาน / จบมินิเกม / จบคดี (ความคืบหน้า ดาว สถิติดีที่สุด และของตกแต่งห้อง)
- **เวอร์ชันถัดไป (แผน):** บัญชีออนไลน์ต่อผู้เล่นหนึ่งคน บันทึกขึ้นคลาวด์อัตโนมัติที่จุดบันทึกเดียวกัน ความคืบหน้า ดาว สถิติดีที่สุด และของตกแต่งห้องผูกกับบัญชี และครอบครัวเล่นด้วยกันโดยแต่ละคนใช้มือถือของตัวเอง

**ยังไม่ล็อก:**
- บัญชี (เวอร์ชันถัดไป): วิธีเข้าสู่ระบบ (เช่น Google / Apple / LINE, บัญชีเด็กที่ผู้ปกครองดูแล)
- บัญชี (เวอร์ชันถัดไป): การทำงานเมื่อออฟไลน์

## 7.4 คดี MVP และโหมดฝึกเล่น
- คดี 01 เป็นคดี MVP สำหรับสร้างและทดสอบระบบ ในเวอร์ชันจริง คดีแรกอาจเป็นเหตุการณ์/คดีที่ง่ายกว่าเพื่อสอนวิธีเล่น (คดีสอนเล่น) — ยังไม่กำหนด
- โหมดฝึกเล่น: มินิเกมประเภทที่เคยเล่นในคดีแล้วจะปลดล็อกที่ "มุมฝึกเล่น" ในห้องของผู้เล่น เมื่อไม่มีคดี/เหตุการณ์ที่กำลังเล่น ผู้เล่นฝึกได้อิสระเพื่อฝึกทักษะ ใช้ชุดด่านฝึกที่ไม่เกี่ยวกับเนื้อเรื่อง (ดูแผนที่ด่านด้านล่าง)
- ดาวในโหมดฝึก (ตัดสินใจแล้ว): ได้ดาวเหมือนในคดีทุกประการ — สูตรเดียวกัน (คำใบ้ในมินิเกมนั้น + เวลาเป้าหมายที่ซ่อนของแต่ละด่าน) เก็บผลดีที่สุด นับรวมความชำนาญและสถิติดีที่สุดชุดเดียวกัน
- แผนที่ด่าน (Map Travel) ในโหมดฝึก: มินิเกมแต่ละประเภทมีแผนที่ด่านของตัวเอง เป็นเส้นทางคดเคี้ยวของด่านที่มีหมายเลข ยากขึ้นทีละนิด ผ่านด่านจึงปลดล็อกด่านถัดไป แต่ละด่านแสดงดาว 1–3 ที่ได้ (สูตรเดียวกัน: คำใบ้ในมินิเกม + เวลาเป้าหมายที่ซ่อน) เก็บผลดีที่สุด
- ธีมแผนที่ (ตัวเลือก): ครอสเวิร์ด = หนังสือพิมพ์/สมุดจด, จิ๊กซอว์ = แผนที่/กระดาษ, เลื่อนบล็อก = ถาดไม้/โรงช่าง
- โจทย์โหมดฝึก (ตัดสินใจแล้ว): ชุดด่านที่เขียนไว้ล่วงหน้าต่อมินิเกม (`practice-packs/<type>/levels`) แต่ละด่านมีพารามิเตอร์และเวลาเป้าหมายที่ซ่อนของตัวเอง
- ความยาก (ยืนยันแล้ว): ตัวเลือกง่าย/ปานกลาง/ยากใช้เฉพาะในคดี แผนที่ด่านไล่ความยากตามลำดับด่านเอง
- มุมฝึกเล่นรองรับมินิเกมจำนวนมาก: หน้าตารางการ์ดเกมเลื่อนได้ 2 คอลัมน์ (แนวตั้ง) การ์ดแสดงไอคอน ชื่อไทย ดาวรวม (x/3×จำนวนด่าน) และด่านที่ไปถึง เกมที่ยังล็อกเป็นเงาสีเข้ม + กุญแจ + "ปลดล็อกจากคดี …" มีชิปกรองหมวด (คำ/ภาพ/ตรรกะ) และป้าย "ใหม่" เมื่อเพิ่งปลดล็อก แตะการ์ดเพื่อเปิดแผนที่ด่าน
- ขยายได้ผ่านทะเบียนมินิเกมใน Story Pack: แต่ละ `type` ลงทะเบียนชื่อ ไอคอน หมวด และชุดด่านฝึก คดีใหม่ที่ใช้ `type` ใหม่จะเพิ่มการ์ดในมุมฝึกเล่นเองโดยไม่ต้องแก้หน้าจอ

## 7.3b จุดแตะบนฉาก (ตัดสินใจแล้ว)
- ไม่แสดงกรอบ เส้นประ หรือเส้นเรืองแสงรอบวัตถุ ใช้ **จุดเล็ก ๆ นิ่ง ๆ (ไม่มีกรอบ/เส้นขอบ)** ต่อจุดที่แตะได้เท่านั้น พื้นที่แตะจริงเป็นรูปทรงวัตถุที่มองไม่เห็น
- แตะแล้วแสดงป้ายชื่อใกล้จุด จากนั้นทำงานต่อ
- ช่องตกแต่งที่ว่าง = จุดกลวงมีเครื่องหมาย + ; ช่องที่วางของแล้ว = แสดงของ + จุดเล็กมาก
- คำใบ้ระดับ 2 = จุดของวัตถุนั้นขยายใหญ่และเปลี่ยนเป็นสีเหลืองค้างไว้ชั่วครู่ (ไม่กะพริบ ไม่ใช้เส้นขอบ)
- ไม่มีอะไรเคลื่อนไหววนซ้ำ (ไม่กะพริบ ไม่เต้น ไม่ขยายหด) ใช้ได้เฉพาะการเฟดเปลี่ยนหน้าจอราว 300 ms
