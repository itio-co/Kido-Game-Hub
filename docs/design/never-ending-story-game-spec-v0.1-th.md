# Never Ending Story Game
## เอกสารข้อกำหนดการออกแบบเกม — รุ่นเริ่มต้น (MVP)

**เวอร์ชัน:** 0.1 — ฉบับร่าง  
**แพลตฟอร์ม:** มือถือ  
**แนวเกมเริ่มต้น:** ผจญภัยไขปริศนาที่เหมาะกับครอบครัว โดยใช้มินิเกมขับเคลื่อนเรื่องราว

## 1. วิสัยทัศน์

เรื่องราวแบบแบ่งตอนที่พัฒนาต่อไปได้เรื่อย ๆ ผู้เล่นร่วมสืบค้นผ่านมินิเกม การค้นพบ และการพูดคุย แต่ละคดีมีบทสรุปที่น่าพอใจ พร้อมทิ้งจุดเชื่อมโยงไปยังตอนถัดไป

**ประสบการณ์หลักที่เกมต้องมอบให้:** ทุกคนถือเรื่องราวคนละส่วน การเล่นและพูดคุยร่วมกันทำให้เห็นภาพใหญ่

“Never Ending” หมายถึงโลกและเรื่องราวที่ขยายต่อไปได้ ไม่ใช่คดีแต่ละคดีที่ไม่มีวันจบ

## 2. ทิศทางการออกแบบที่ตกลงร่วมกัน

| ประเด็น | แนวทาง |
|---|---|
| กลุ่มผู้เล่น | เด็ก ผู้ใหญ่ และผู้สูงอายุสามารถเล่นร่วมกันได้ |
| อุปกรณ์ | แต่ละคนใช้มือถือของตัวเอง และเข้าร่วมคดีเดียวกัน |
| รูปแบบการมีส่วนร่วม | ลักษณะคดีเป็นตัวกำหนดว่าจะเล่นเดี่ยว เป็นทีมเล็ก หรือร่วมกันทั้งคอมมูนิตี้ |
| ข้อมูล | ผู้เล่นอาจได้รับเบาะแสต่างกัน และนำสิ่งที่ค้นพบมาแลกเปลี่ยนกัน |
| ความยาก | ผู้เล่นเลือกเป็นรายบุคคล ไม่กำหนดอัตโนมัติจากอายุ |
| ตัวตน | ผู้เล่นเลือกอวตารและตัวตนภายในเกม |
| ความหลากหลาย | ใช้ AI ช่วยแต่งเรื่องและสร้างโจทย์มินิเกมที่หลากหลาย ภายใต้กติกาที่สอดคล้องกัน |
| ความต่อเนื่อง | เรื่องหลักและเรื่องย่อยสามารถพัฒนาต่อเนื่องข้ามตอนได้ |
| เนื้อหาตามเทศกาล | เพิ่มธีมเป็นครั้งคราวให้ตรงกับเทศกาลหรือโอกาสในโลกจริง ไม่ใช้เป็นแกนถาวรของเกม |

## 3. ขอบเขต MVP ที่เสนอ

เริ่มจาก **คดีในห้องส่วนตัวหนึ่งคดี สำหรับผู้เล่น 1–3 คน** เพื่อทดลองทั้งการเล่นเดี่ยวและการร่วมมือกัน

ประกอบด้วยตอนเริ่มต้นหนึ่งตอน พร้อมรูปแบบย่อยที่ผ่านการตรวจสอบจำนวนไม่มาก แม่แบบมินิเกมที่นำกลับมาใช้ได้สองแบบ อวตารสำเร็จรูป ความยากสามระดับ กระดานคดีร่วม แชทข้อความภายในทีม และการบันทึกความคืบหน้า

แม่แบบมินิเกมเริ่มต้นสองแบบคือ **การสังเกตและจับคู่เบาะแส** กับ **การถอดรหัสสัญลักษณ์** แต่ละปริศนาต้องเปิดเผยหลักฐานหรือทำให้การสืบคืบหน้า ไม่ใช่กิจกรรมแทรกที่ไม่เกี่ยวกับเรื่อง

ระบบจับคู่ผู้เล่นสาธารณะ ภารกิจที่คอมมูนิตี้จำนวนมากช่วยกันแบ่งงาน กิจกรรมเทศกาล แชทเสียง และเนื้อเรื่องแตกแขนงขนาดใหญ่ ยังไม่อยู่ในรุ่นเริ่มต้น จำนวนผู้เล่นสูงสุดและแม่แบบที่เลือกใช้ยังเป็นข้อเสนอสำหรับนำไปทดสอบ

## 4. วงจรการเล่นหลัก

**เลือกอวตารและความยาก → เริ่มหรือเข้าร่วมคดี → รับฉากเนื้อเรื่องและเบาะแสตามบทบาท → เล่นมินิเกม → พูดคุยและแบ่งปันหลักฐาน → ส่งข้อสรุป → เปิดเผยผลและปมเชื่อมไปตอนถัดไป**

เมื่อจบคดี ระบบบันทึกผลให้ผู้เข้าร่วม ปมที่เชื่อมไปยังตอนต่อไปควรทำให้อยากกลับมาเล่น โดยไม่กั๊กบทสรุปของคดีปัจจุบัน

## 5. ส่วนติดต่อผู้ใช้บนมือถือ

**รูปแบบที่เสนอ:** ออกแบบให้เหมาะกับหน้าจอแนวตั้งเป็นหลัก ใช้ภาพประกอบ สมุดนักสืบ และกระดานคดี แทนโลกสามมิติที่เดินสำรวจได้อย่างอิสระ

| หน้าจอ | หน้าที่ |
|---|---|
| ศูนย์รวมเรื่องราว | เล่นตอนปัจจุบันต่อ หรือดูคดีที่เปิดให้เล่น |
| ห้องคดี | เชิญผู้ร่วมเล่น เลือกอวตาร และดูว่าใครพร้อมแล้ว |
| ฉากเนื้อเรื่อง | อ่านบทสนทนาของตัวละครและทำความเข้าใจเป้าหมายปัจจุบัน |
| เบาะแสของฉัน | ตรวจดูหลักฐานส่วนตัวและเปิดมินิเกมที่เกี่ยวข้อง |
| กระดานคดีร่วม | รวบรวมหลักฐานที่ผู้เล่นเลือกแบ่งปัน และนำมาประกอบข้อสรุป |
| แชททีม | พูดคุยแลกเปลี่ยนข้อสันนิษฐานและส่งการ์ดเบาะแส โดยไม่ต้องออกจากคดี |

ปุ่มแชร์เบาะแสและข้อความสำเร็จรูปที่เลือกใช้ได้ช่วยลดการพิมพ์ซ้ำ **มีไว้สนับสนุนการพูดคุย ไม่ใช่แทนที่การพูดคุย** ส่วนการสื่อสารด้วยเสียงยังเป็นเรื่องที่ต้องตัดสินใจภายหลัง

ใช้ปุ่มและพื้นที่สัมผัสขนาดใหญ่ ปรับขนาดตัวอักษรได้ มีป้ายกำกับชัดเจน และไม่ใช้สีเพียงอย่างเดียวในการสื่อเบาะแส รุ่น MVP ไม่บังคับจับเวลา

## 6. ตัวอย่างคดีเริ่มต้น: อัลบั้มครอบครัวที่หายไป

ครอบครัวกำลังเตรียมงานรวมญาติ แต่อัลบั้มภาพกลับหายไป กระดาษข้อความปริศนาเป็นจุดเริ่มต้นของการตามหา

| บทบาท | ข้อมูลส่วนตัว | สิ่งที่ช่วยทีมได้ |
|---|---|---|
| นักสังเกต | กระดาษที่มีชุดสัญลักษณ์เรียงกัน | ระบุและแบ่งปันสัญลักษณ์ที่เกี่ยวข้อง |
| นักถอดรหัส | ตารางเทียบสัญลักษณ์กับคำ | แปลข้อความออกมาเป็น “กล่องสีน้ำเงิน” |
| นักนำทาง | แผนผังจุดเก็บของในบ้านที่มีป้ายกำกับ | ระบุตำแหน่งกล่องสีน้ำเงินในห้องทำงาน |

ผู้เล่นนำข้อมูลมาประกอบกันจนพบอัลบั้ม ภายในมีโปสการ์ดที่ไม่มีใครคุ้นเคย ซึ่งเชื่อมไปสู่ตอนถัดไป

เมื่อเล่นสองคน ให้รวมบางบทบาทเข้าด้วยกัน เมื่อเล่นคนเดียว ให้สมุดบันทึกหรือตัวละครช่วยเหลือในเกม (NPC) มอบหลักฐานของบทบาทอื่น คดีในอนาคตไม่จำเป็นต้องรองรับทุกขนาดกลุ่ม

## 7. ความยากและการร่วมมือ

ผู้เล่นเลือก **สบาย ๆ / นักสืบ / ท้าทาย** และเปลี่ยนภายหลังได้ ระดับความยากปรับความซับซ้อนของเบาะแส การชี้แนะ และคำใบ้ที่เลือกใช้ได้ แต่ไม่เปลี่ยนข้อเท็จจริงของคดี

**บทบาทกำหนดว่าผู้เล่นได้รับข้อมูลอะไร ส่วนความยากกำหนดว่างานของคนนั้นท้าทายเพียงใด** ทีมที่เลือกระดับต่างกันต้องยังไขคดีเดียวกันได้ และทุกบทบาทควรมีส่วนช่วยอย่างมีความหมาย

สามารถใส่กิจกรรมสังเกตและจดจำเป็นส่วนหนึ่งของการเล่นได้ โดยไม่กล่าวอ้างประโยชน์ทางการแพทย์หรือผลในการพัฒนาความจำ

เบาะแสส่วนตัวต้องยังเป็นส่วนตัวจนกว่าผู้เล่นจะแชร์ หลักฐานที่แชร์แล้วและขั้นตอนที่ทำสำเร็จต้องคงอยู่เมื่อเชื่อมต่อกลับมา รุ่น MVP ใช้ห้องแบบเชิญเท่านั้น และต้องกำหนดวิธีโอนบทบาทหรือพักคดี เพื่อไม่ให้ผู้เล่นที่หลุดการเชื่อมต่อทำให้คดีติดค้างถาวร

## 8. AI ช่วยสร้างเนื้อหาและการสุ่มที่ควบคุมได้

**แนวทางที่เสนอสำหรับ MVP:** ใช้ AI เป็นผู้ช่วยเขียน เพื่อเตรียมคดีรูปแบบย่อยที่ผ่านการตรวจสอบ แทนการสร้างเนื้อหาอย่างไร้ข้อจำกัดระหว่างเล่นจริง

**กำหนดความจริงของคดี → วางหลักฐานที่จำเป็น → จัดหลักฐานเข้าบทบาทและแม่แบบมินิเกม → เขียนฉากและคำใบ้ → ตรวจสอบและทดลองเล่น → เผยแพร่รูปแบบที่ผ่านการอนุมัติ**

เปลี่ยนสถานการณ์ตั้งต้น ตำแหน่งเบาะแส การแบ่งบทบาท และรายละเอียดโจทย์ได้ โดยรักษาตัวละครและข้อเท็จจริงที่วางไว้ เมื่อเริ่มคดีแล้ว คำตอบของคดีต้องไม่เปลี่ยนระหว่างทาง

การตรวจสอบเชิงโครงสร้างควรยืนยันว่ามีเบาะแสจำเป็นครบ คำตอบสอดคล้องกัน และมีเส้นทางเล่นจนจบได้ การตรวจทานโดยคนและการทดลองเล่นใช้ตรวจความสมเหตุสมผลของเรื่อง ความเป็นธรรม และความเหมาะสมสำหรับครอบครัว หากเนื้อหาที่สร้างไม่ผ่านการตรวจสอบ ให้กลับไปใช้รูปแบบที่อนุมัติไว้แล้ว

AI สร้างเนื้อเรื่องและเนื้อหาโจทย์ ส่วนแม่แบบที่มีอยู่ในเกมเป็นตัวดำเนินกลไกการเล่น ไม่จำเป็นต้องให้ AI เขียนโค้ดเกมใหม่ทุกคดี

## 9. สิ่งที่ MVP ต้องพิสูจน์

ต้นแบบควรแสดงให้เห็นว่า:

- ผู้เล่นบนมือถือคนละเครื่องสามารถใช้เบาะแสที่ต่างกันเพื่อจบคดีร่วมกันได้
- ระดับความยากที่ต่างกันไม่ทำให้คดีขัดแย้งหรือแก้ไม่ได้ และทุกคนยังมีส่วนช่วยอย่างมีความหมาย
- การพูดคุยช่วยให้ค้นพบคำตอบ ขณะที่เครื่องมือแชร์ข้อมูลยังใช้งานง่าย
- คดีเริ่มต้นเล่นคนเดียวได้ บันทึกความคืบหน้าได้ และเชื่อมต่อกลับมาเล่นต่อได้
- รูปแบบย่อยที่ผ่านการอนุมัติทำให้การสืบแตกต่างออกไป โดยไม่ขัดกับหลักฐานของตัวเอง
- ตอนจบคลี่คลายคดีปัจจุบัน และทำให้ผู้เล่นอยากรู้เรื่องราวตอนต่อไป

## 10. การขยายหลังผ่านการทดสอบ

ขยายเป็นเส้นเรื่องหลัก เรื่องย่อยที่เลือกเล่นได้ แม่แบบมินิเกมเพิ่มเติม และคดีระดับคอมมูนิตี้ที่ผู้เล่นจำนวนมากแบ่งการสืบสวนขนาดใหญ่ออกเป็นงานย่อยเพื่อช่วยกันทำ

เพิ่มตอนตามเทศกาลเมื่อสอดคล้องกับโอกาสในโลกจริง ให้เป็นเรื่องราวพิเศษชั่วคราว ไม่ใช่สิ่งที่ประสบการณ์หลักของเกมต้องพึ่งพา

**ลำดับความสำคัญตอนนี้:** ทำคดีหนึ่งคดีให้สนุกและเข้าใจง่ายบนมือถือ ก่อนเพิ่มจำนวนเนื้อหาหรือจำนวนผู้เล่น
