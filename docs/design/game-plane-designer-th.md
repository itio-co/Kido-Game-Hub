# ชั้นเกมนักออกแบบ (Designer game plane)

> **game plane = ชั้นเกม** — อีกชั้นหนึ่งของตัวเกมเอง ไม่ใช่แผนอนาคต

## ชั้นเกม 2 ชั้น
| ชั้นเกม (game plane) | ผู้เล่นเป็น | ทำอะไร |
|---|---|---|
| ชั้นเล่นเรื่อง (story-play plane) | นักสืบฝึกหัด (มีพลังควบคุมเวลา) | เล่นคดี สำรวจห้อง ย้อนเวลา แก้มินิเกม |
| **ชั้นนักออกแบบ (designer plane)** | **นักออกแบบเกม** (สวมบทบาท) | สร้างเกม/คดีของตัวเอง: ตัวละคร ห้อง วัตถุ ช่วงเวลา เบาะแส การ์ตูนเปิดเรื่อง ธีมปฏิทิน |

## ตอนนี้ทำงานอย่างไร
- ชั้นนักออกแบบตอนนี้เล่นผ่าน **การแชตกับ Grok Bot**: ผู้เล่นบอกไอเดีย Grok Bot ช่วยเขียน Story Pack (`case.json`) สร้างภาพ low-poly และอัปเดตต้นแบบ
- **คลังแอสเซต (Asset Showcase)** เป็นส่วนหนึ่งของชั้นนี้ — เป็นหน้าที่นักออกแบบใช้ดูว่าเกมมีอะไรบ้าง: [`prototypes/asset-showcase/`](../../prototypes/asset-showcase/index.html) · รายการ: [asset-list-th.md](asset-list-th.md)
- ผลงานจากชั้นนักออกแบบ = Story Pack ใหม่ ซึ่งชั้นเล่นเรื่องเปิดเล่นได้ทันทีในหน้าเลือกเหตุการณ์ โดยไม่ต้องแก้โค้ด

## ยังเปิดอยู่ (ยังไม่ตัดสินใจ)
- เครื่องมือในเกมสำหรับชั้นนักออกแบบ (นอกเหนือจากแชต) หน้าตา และการแชร์คดีที่ผู้เล่นสร้าง
- การตรวจความเหมาะสมของเนื้อหาที่ผู้เล่นสร้างสำหรับครอบครัว
