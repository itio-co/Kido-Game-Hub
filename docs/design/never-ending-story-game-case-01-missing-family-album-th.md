# Never Ending Story Game
## คดี 01: อัลบั้มครอบครัวที่หายไป
### ร่างเนื้อเรื่องและลำดับการเล่น

**เวอร์ชัน:** 0.1 — ฉบับร่างสำหรับทดลองเล่น  
**วันที่:** 22 ตุลาคม 2026  
**รูปแบบ:** เกมมือถือแนวตั้ง มุมมองห้อง isometric  
**ผู้เล่น:** ฝึกเดี่ยวก่อน จากนั้นเล่นคดีคนเดียวหรือทีมส่วนตัว 2–3 คน  
**สถานที่:** ห้องนั่งเล่นหนึ่งห้อง  
**อารมณ์:** อบอุ่น ชวนสงสัย มีช่วงค้นพบและเซอร์ไพรส์ โดยไม่มีความรุนแรง  
**เวลาเป้าหมายที่เสนอ:** บทฝึกประมาณ 3–5 นาที และคดีประมาณ 15–20 นาที ต้องตรวจสอบด้วยการทดลองเล่น ไม่ใช่เวลาจำกัด

> **ฐานการออกแบบ:** ใช้แนวคิดคดีจากสเปก MVP v0.1 และข้อสรุปล่าสุดในบทสนทนา ได้แก่ ห้อง isometric แนวตั้ง คลังมินิเกมสามแบบ การฝึกเดี่ยว และความชำนาญของอวตาร ชื่อตัวละคร บทสนทนา เหตุการณ์ และรายละเอียดโจทย์ด้านล่างเป็นข้อเสนอใหม่สำหรับคดีนี้ ไม่ใช่ข้อกำหนดที่ตกลงไว้แล้วทั้งหมด
>
> **ความต่างจากตัวอย่างเดิม:** ร่างนี้ใช้ครอสเวิร์ด จิ๊กซอว์ และเกมเลื่อนบล็อก แทนเส้นทางถอดรหัสสัญลักษณ์เดิม และรวมสถานที่ไว้ในห้องนั่งเล่นเดียว เอกสารนี้เป็นไฟล์เนื้อหาคดีแยกต่างหาก ไม่แก้ทับสเปกหลัก

## 1. เรื่องย่อ

ช่วงบ่ายก่อนทุกคนในครอบครัวจะมารวมตัวกัน คุณยายมะลิกำลังเตรียมเปิดอัลบั้มเก่าให้หลาน ๆ ดู แต่บนโต๊ะกลับเหลือเพียงรอยว่างสี่เหลี่ยม ผ้าเช็ดโต๊ะ และกระดาษข้อความว่า **“ขอย้ายเก็บก่อน — ริน”**

อัลบั้มถูกย้ายไปไหน และทำไมต้องรีบเก็บ?

ผู้เล่นช่วยกันสำรวจห้อง คุยกับลุงเมฆ ประกอบแผนผังเก็บของที่หล่นกระจัดกระจาย และนำข้อมูลมารวมกันเพื่อเลือกกล่องที่ถูกต้อง กล่องนั้นมีตัวล็อกของเล่นซึ่งต้องเลื่อนบล็อกให้กุญแจถึงทางออก

เมื่อพบอัลบั้ม ทุกคนจึงรู้ว่าไม่ได้มีใครขโมย น้ารินเพียงย้ายมันออกจากโต๊ะที่เปียกน้ำ แล้วเก็บไว้ตามระบบจัดของเดิมของบ้าน แต่การเปิดอัลบั้มกลับทำให้พบ **โปสการ์ดเก่าที่ไม่มีใครรู้ว่าใส่ไว้เมื่อไร** พร้อมข้อความชี้ไปยังห้องสมุดแห่งหนึ่ง

**คดีของหายจบลง แต่เรื่องราวของโปสการ์ดเพิ่งเริ่มต้น**

## 2. ความจริงของคดี — สำหรับทีมพัฒนา

กำหนดข้อเท็จจริงต่อไปนี้ให้คงที่ตลอดการเล่นหนึ่งรอบ

| คำถาม | คำตอบจริง |
|---|---|
| ใครย้ายอัลบั้ม? | น้าริน |
| ย้ายทำไม? | น้ำจากแจกันหกบนโต๊ะ จึงย้ายอัลบั้มออกก่อนจะเปียก |
| เก็บไว้ที่ไหน? | กล่องสีน้ำเงินติดรูปดาว ใต้หน้าต่าง |
| ทำไมต้องใช้กล่องนี้? | เป็นกล่องเก็บภาพครอบครัว และอยู่ในโซนภาพถ่ายตามผังเก็บของเดิม |
| ทำไมเปิดไม่ได้ทันที? | กล่องมีตัวล็อกของเล่นแบบเลื่อนบล็อก ซึ่งปิดกลับเมื่อเก็บของ |
| มีคนร้ายหรือไม่? | ไม่มี เป็นคดีตามหาสิ่งของ ไม่ใช่การหาคนผิด |
| โปสการ์ดเกี่ยวกับการย้ายอัลบั้มหรือไม่? | ไม่เกี่ยว น้ารินไม่ได้ใส่มันลงไป เป็นปมของตอนถัดไป |

รอยน้ำ ผ้าเช็ดโต๊ะ และข้อความของน้ารินต้องพบได้ตั้งแต่ต้น เพื่อให้ตอนเฉลยอธิบายสิ่งที่ผู้เล่นเห็นมาแล้ว ไม่ใช่เพิ่มเหตุผลขึ้นทีหลัง

## 3. ตัวละครและห้องหลัก

### ตัวละคร

| ตัวละคร | บทบาทในเรื่อง | ตัวอย่างน้ำเสียง |
|---|---|---|
| คุณยายมะลิ | ผู้ขอให้ช่วยตามหาอัลบั้ม และผู้สอนในบทฝึก | ใจเย็น ชวนคิด ไม่ตำหนิเมื่อผู้เล่นตอบผิด |
| ลุงเมฆ | กำลังเตรียมหน้าครอสเวิร์ดสำหรับเล่นกับครอบครัว และเห็นบางส่วนของการย้ายของ | เป็นกันเอง ชอบเกมคำศัพท์ ให้ข้อมูลที่รู้โดยไม่กั๊ก |
| น้าริน | ผู้จัดห้องและย้ายอัลบั้ม ออกไปเตรียมของอีกมุมบ้านก่อนกลับมาในตอนเฉลย | พูดตรง อธิบายเหตุการณ์อย่างธรรมดา ไม่ทำตัวเป็นผู้ต้องสงสัยลึกลับ |
| อวตารผู้เล่น | ผู้ช่วยสำรวจและแก้ปัญหา | ใช้ชื่อและรูปลักษณ์ที่ผู้เล่นเลือก ไม่กำหนดอายุของตัวละครตามผู้เล่นจริง |

### จุดสำรวจในห้อง isometric

| จุด | สิ่งที่พบหรือทำได้ |
|---|---|
| โต๊ะกลาง | รอยวางอัลบั้ม รอยน้ำ ผ้าเช็ดโต๊ะ และข้อความของน้าริน |
| โซฟา | คุยกับลุงเมฆ และเล่นครอสเวิร์ด |
| ถาดข้างชั้นหนังสือ | ชิ้นส่วนแผนผังเก็บของแบบจิ๊กซอว์ |
| ใต้หน้าต่าง | กล่องสีน้ำเงินรูปดาว และกล่องสีเหลืองรูปใบไม้ |
| ข้างโซฟา | กล่องสีน้ำเงินรูปดาวอีกใบ ใช้เป็นตัวเลือกที่ต้องตรวจสอบตำแหน่ง |
| กระดานคดี | เปิดเป็นแผงจากด้านล่างของจอ เพื่อรวมการ์ดหลักฐาน |

ใช้ทั้ง **สัญลักษณ์และตำแหน่ง** ในการระบุกล่อง ไม่ให้สีเป็นข้อมูลสำคัญเพียงอย่างเดียว กล้องคงมุมใน MVP; แตะวัตถุแล้วเปิดภาพขยายหรือมินิเกม

## 4. บทนำ: นักสืบฝึกหัด — เล่นคนเดียว

### ฉากเปิด

อวตารเข้ามาในห้องก่อนเริ่มคดี คุณยายมะลิวางถาดเกมเล็ก ๆ ลงบนโต๊ะ

> **ยายมะลิ:** “ก่อนช่วยยายจัดบ้าน มาลองของเล่นสามอย่างนี้กันก่อนนะ ไม่ต้องรีบ ลองใหม่ได้เสมอ”

บทนี้สอนการแตะวัตถุ การเปิดคำใบ้ และการเล่นมินิเกม ไม่ใช้เบาะแสจริงของคดี เพื่อไม่เฉลยเนื้อเรื่องล่วงหน้า

| งานฝึก | ตัวอย่างโจทย์ | สิ่งที่ผู้เล่นได้ลอง |
|---|---|---|
| ครอสเวิร์ด | ตารางเล็กพร้อมคำใบ้และภาพประกอบ | เลือกคำ เติมช่อง และดูคำที่ตัดกัน |
| จิ๊กซอว์ | ต่อภาพกระถางต้นไม้ 4 ชิ้น | ลากชิ้นภาพเข้าตำแหน่ง และดูภาพตัวอย่าง |
| เลื่อนบล็อก | ขยับบล็อกเปิดทางให้กุญแจของเล่น | เข้าใจกติกาแนวเลื่อน ช่องออก และปุ่มย้อนกลับ |

เมื่อจบบทฝึก ให้เปิดทักษะแรกตามเนื้อเรื่องโดยอัตโนมัติ เสนอชื่อชั่วคราวว่า **“มองอีกมุม”** ใช้เปิดคำใบ้เฉพาะโจทย์เพิ่มได้หนึ่งขั้น โดยไม่เฉลยทุกอย่างทันที

ความชำนาญด้านภาษา มิติสัมพันธ์ และตรรกะเริ่มบันทึกจากการเล่นที่เกี่ยวข้อง แต่ยังไม่กำหนดสูตรคะแนนหรือระดับในเอกสารนี้ การฝึกซ้ำไม่เป็นเงื่อนไขบังคับก่อนเข้าคดี และคำใบ้พื้นฐานยังใช้ได้โดยไม่ต้องมีค่าความชำนาญสูง

> **ยายมะลิ:** “เก่งคนละอย่างก็ช่วยกันได้ เดี๋ยวถ้ามีงานที่ถนัดไม่เหมือนกัน เราค่อยแบ่งกันทำนะ”

หลังบทฝึก เลือก **เล่นคดีต่อคนเดียว** หรือ **เชิญเพื่อนเข้าห้อง** ได้ ผู้เล่นที่เคยฝึกครบแล้วไม่ต้องเรียนซ้ำ

## 5. เส้นทางการเล่นของคดี

```text
บทฝึกเดี่ยว
  ↓
พบว่าอัลบั้มหาย → สำรวจโต๊ะและรับเป้าหมาย
  ↓
สำรวจแยกงานกันได้
  ├─ คุยกับลุงเมฆ → รู้สัญลักษณ์กล่อง
  │                  └─ ช่วยครอสเวิร์ดเป็นงานเสริม
  ├─ ต่อแผนผังจิ๊กซอว์ → รู้โซนเก็บภาพถ่าย
  └─ อ่านบันทึกน้าริน → รู้ว่าเก็บตามผังเดิม
  ↓
แชร์หลักฐาน → เลือกกล่องรูปดาวใต้หน้าต่าง
  ↓
เลื่อนบล็อกบนตัวล็อกของเล่น → พบอัลบั้ม
  ↓
เฉลยเหตุการณ์ → พบโปสการ์ด → บันทึกคดีสำเร็จ
```

**ข้อเสนอสำหรับร่างนี้:** ครอสเวิร์ดในคดีเป็นงานเสริมที่เล่นได้จริงและให้ความชำนาญ แต่ไม่ใช้การปิดบังข้อมูลของ NPC มาบังคับผู้เล่น ส่วนจิ๊กซอว์และเลื่อนบล็อกอยู่บนเส้นทางหลัก ทั้งสามแบบมีบทฝึกและกลับไปเล่นจากคลังได้

การสำรวจ แชร์ข้อมูล และสรุปบนกระดานคดีเป็นกิจกรรมสืบสวน ไม่เพิ่มเป็นแม่แบบมินิเกมใหม่ใน MVP

## 6. เนื้อหาทีละฉาก

### ฉาก 1 — ที่ว่างบนโต๊ะ

**ภาพเปิด:** กล้องเห็นทั้งห้อง คุณยายถือผ้าปูโต๊ะอยู่ข้างโซฟา บนโต๊ะกลางมีรอยว่างขนาดเท่าอัลบั้มและแจกันที่ถูกย้ายไปด้านข้าง

> **ยายมะลิ:** “เมื่อเช้ายายวางอัลบั้มไว้ตรงนี้ ตั้งใจจะเปิดรูปเก่าให้ทุกคนดู ตอนนี้เหลือแต่ที่ว่างเสียแล้ว”
>
> **ยายมะลิ:** “ช่วยดูให้หน่อยได้ไหม ว่าใครย้ายไปเก็บตรงไหน?”

ผู้เล่นแตะโต๊ะ พบกระดาษด้านหน้าว่า **“ขอย้ายเก็บก่อน — ริน”** เมื่อพลิกดู จะมีข้อความต่อว่า **“เก็บตามผังเดิมนะ โต๊ะยังเปียกอยู่”**

**เป้าหมายบนจอ:** “ตามหาอัลบั้มครอบครัว”  
**เป้าหมายย่อย:** “หาว่าใช้กล่องแบบไหน และเก็บไว้ตรงไหน”

ได้รับการ์ดหลักฐาน `E01 — ข้อความของน้าริน` และ `E02 — โต๊ะที่เปียก` การพบหลักฐานไม่ทำให้เกมกล่าวหาน้ารินหรือให้คะแนนการจับคนผิด

### ฉาก 2 — คำบอกเล่าข้างโซฟา

ลุงเมฆนั่งเตรียมหน้าครอสเวิร์ดสำหรับเล่นกับครอบครัว ผู้เล่นเลือกถามเรื่องอัลบั้มได้ทันที

> **ลุงเมฆ:** “รินเอาอัลบั้มใส่กล่องที่ติดรูปดาว ลุงเห็นตอนเธอยกผ่านโต๊ะ แต่ไม่ได้มองว่าเอาไปวางที่ไหน”
>
> **ลุงเมฆ:** “ถ้าชอบเกมคำศัพท์ มาช่วยลุงเติมหน้านี้ด้วยก็ได้นะ อีกไม่กี่คำเอง”

ได้รับ `E03 — กล่องมีรูปดาว` โดยไม่ต้องชนะครอสเวิร์ดก่อน

**งานเสริม:** “เติมหน้าครอสเวิร์ดให้ครอบครัว” ใช้ตารางและเฉลยในหัวข้อ 9 ผู้เล่นรับงานไว้แล้วกลับมาทำภายหลังก่อนออกจากตอนได้

เมื่อทำสำเร็จ:

> **ลุงเมฆ:** “ครบแล้ว! เดี๋ยวให้ทุกคนลองเล่นกัน ขอบใจมากนะ”

เพิ่มความชำนาญด้านภาษาของอวตารตามกติกาที่จะกำหนดภายหลัง ไม่มีหลักฐานจำเป็นซ่อนอยู่หลังรางวัลงานเสริมนี้

### ฉาก 3 — ผังเก็บของที่กระจัดกระจาย

ที่ถาดข้างชั้นหนังสือมีชิ้นส่วนภาพแม่เหล็กอยู่หลายชิ้น บ้านนี้ใช้ภาพต่อเป็นแผนผังช่วยจัดหมวดของ แต่ระหว่างจัดห้องกระดานหล่นจนชิ้นภาพหลุดจากกรอบ

> **ยายมะลิ:** “นั่นผังเก็บของของบ้านเรา รินบอกว่าเก็บตามผังเดิม ลองต่อให้เห็นทั้งภาพสิ”

**มินิเกมหลักที่ 1:** จิ๊กซอว์แผนผังห้อง

เมื่อประกอบเสร็จ ภาพแสดงหมวด **“ภาพถ่ายและจดหมาย”** อยู่ในโซนใต้หน้าต่าง ส่วนโซนข้างโซฟาเป็นของเล่น ภาพไม่ได้บอกสัญลักษณ์บนกล่อง จึงยังต้องนำไปประกอบกับคำบอกเล่าของลุงเมฆ

ได้รับ `E04 — ภาพถ่ายเก็บใต้หน้าต่าง`

**จังหวะให้คุยกัน:** ผู้เล่นที่ต่อภาพเสร็จเห็นปุ่ม “แชร์แผนผัง” พร้อมข้อความชวนคุยว่า **“ข้อมูลนี้ช่วยแยกกล่องสองใบที่มีรูปดาวได้ไหม?”** ไม่ส่งคำตอบเข้ากระดานกลางโดยอัตโนมัติ

### ฉาก 4 — กล่องรูปดาวใบไหน?

ผู้เล่นเปิดกระดานคดีเพื่อรวมข้อมูล

| หลักฐาน | สิ่งที่บอก |
|---|---|
| ข้อความของน้าริน | อัลบั้มถูกเก็บตามผังเดิม |
| คำบอกเล่าลุงเมฆ | กล่องมีรูปดาว |
| แผนผังที่ประกอบแล้ว | หมวดภาพถ่ายอยู่ใต้หน้าต่าง |

กระดานให้เลือกการ์ดข้อมูลที่สนับสนุนข้อสรุป แล้วแตะกล่องในห้อง ไม่จำเป็นต้องพิมพ์คำตอบยาว

**ข้อสรุปที่ถูกต้อง:** “กล่องรูปดาวใต้หน้าต่าง”

ถ้าเลือกกล่องรูปดาวข้างโซฟา:

> **ข้อความช่วยคิด:** “สัญลักษณ์ตรงแล้ว แต่ตำแหน่งนี้ตรงกับผังเก็บภาพถ่ายหรือยัง?”

ถ้าเลือกกล่องรูปใบไม้ใต้หน้าต่าง:

> **ข้อความช่วยคิด:** “อยู่ในโซนที่หาแล้ว ลองเทียบสัญลักษณ์กับสิ่งที่ลุงเมฆเห็นอีกครั้ง”

ไม่ลดคะแนน ไม่ทำหลักฐานหาย และไม่เริ่มคดีใหม่ เมื่อเลือกถูกจึงเปิดงานตรวจกล่องเป้าหมาย กล่องอื่นไม่ต้องมีมินิเกมหรือฉากภายในแยก

### ฉาก 5 — ตัวล็อกของเล่น

บนฝากล่องเป็นกระดานเลื่อนบล็อกเล็ก ๆ มีกุญแจรูปการ์ตูนอยู่ในราง

> **ยายมะลิ:** “กล่องนี้ใช้ตัวล็อกของเล่นแบบที่ลองเมื่อกี้เลย ลองขยับชิ้นอื่นให้กุญแจผ่านได้สิ”

**มินิเกมหลักที่ 2:** เลื่อนบล็อกพากุญแจออกจากกรอบ

ผู้เล่นที่รับหน้าที่กด “ขอเพื่อนช่วย” ได้ เมื่อเพื่อนรับคำขอ ระบบโอนสิทธิ์ควบคุมกระดานเดิม ไม่สร้างโจทย์อีกชุด และไม่เริ่มความคืบหน้าใหม่ ทุกคนยังคุยแนะนำกันได้

เมื่อสำเร็จ มีเสียงคลิกเบา ๆ ฝากล่องเปิด เห็นอัลบั้มอยู่บนสุดอย่างปลอดภัย

> **ยายมะลิ:** “เจอแล้ว! หน้าปกดอกไม้เล่มนี้เอง”

ได้รับ `E05 — พบอัลบั้มในกล่อง` และเปลี่ยนเป้าหมายเป็น **“นำอัลบั้มกลับไปให้ยายมะลิ”**

### ฉาก 6 — ไม่ได้หาย แค่ถูกเก็บ

อัลบั้มถูกวางบนโต๊ะที่เช็ดแห้งแล้ว น้ารินกลับเข้ามาในห้อง

> **ริน:** “หาเจอแล้วใช่ไหม? เมื่อกี้น้ำหกบนโต๊ะ ฉันเลยรีบยกอัลบั้มใส่กล่อง แล้วทิ้งข้อความไว้”
>
> **ยายมะลิ:** “คราวหน้าช่วยเขียนด้วยนะว่าอยู่กล่องไหน วันนี้ทุกคนช่วยกันเป็นนักสืบเลย”
>
> **ริน:** “ได้เลย ครั้งหน้าเขียนให้ครบทั้งกล่องทั้งตำแหน่ง”

ขึ้นสรุปคดีเป็นภาพสั้น ๆ: **น้ำหก → น้ารินย้ายอัลบั้ม → เก็บในกล่องรูปดาวใต้หน้าต่าง → ผู้เล่นช่วยกันพบ**

แสดงว่า **“คดีอัลบั้มครอบครัวที่หายไป — สำเร็จ”** ก่อนเริ่มปมใหม่ เพื่อให้ผู้เล่นได้รับบทสรุปของคดีนี้อย่างชัดเจน

### ฉาก 7 — โปสการ์ดในหน้าสุดท้าย

คุณยายเปิดดูรูปครอบครัวสองสามหน้า ก่อนพบโปสการ์ดสอดอยู่ในซองด้านหลังอัลบั้ม ด้านหน้าเป็นภาพอาคารเล็ก ๆ มีป้าย **“ห้องสมุดวันวาน”**

ด้านหลังเขียนว่า:

> “ภาพที่เหลือฝากไว้ที่ห้องสมุดวันวาน — ลิ้นชักหมายเลข 7”

> **ยายมะลิ:** “ยายไม่คุ้นโปสการ์ดใบนี้เลย ใครเอามาสอดไว้นะ?”
>
> **ริน:** “ตอนย้ายฉันไม่ได้เปิดอัลบั้ม แล้วก็ไม่ได้ใส่อะไรเพิ่มด้วย”

ผู้เล่นแตะเก็บเป็น `H01 — โปสการ์ดห้องสมุดวันวาน`

**ปิดตอน:** อวตารวางโปสการ์ดลงในสมุดนักสืบ หน้าใหม่แสดงชื่อคดีชั่วคราว **“ภาพที่เหลือในลิ้นชักหมายเลข 7”**

MVP จบที่หน้าตัวอย่างนี้ ยังไม่ต้องสร้างห้องสมุดหรือคดีที่สอง ไม่มีเวลานับถอยหลัง และไม่ทำให้รางวัลของคดีแรกขึ้นกับการเล่นต่อทันที

## 7. การแบ่งงานเมื่อเล่นหลายคน

ทุกคนเห็นห้องเดียวกันบนเครื่องตัวเอง แต่ได้รับงานและข้อมูลเริ่มต้นต่างกัน ไม่ใช่เห็นความจริงคนละชุด

| ผู้เล่น | งานเริ่มต้นที่เสนอ | สิ่งที่นำไปช่วยทีม |
|---|---|---|
| คนที่ 1 | คุยกับลุงเมฆและรับครอสเวิร์ดตามความสนใจ | ข้อมูลว่ากล่องติดรูปดาว |
| คนที่ 2 | ประกอบแผนผังจิ๊กซอว์ | ข้อมูลว่าโซนภาพถ่ายอยู่ใต้หน้าต่าง |
| คนที่ 3 | ตรวจโต๊ะ อ่านข้อความน้าริน และรับงานกลไกเมื่อเจอกล่อง | ข้อมูลว่าเก็บตามผังเดิม เหตุผลที่ย้าย และการเปิดกล่อง |

การแบ่งนี้เป็นหน้าที่เริ่มต้น ไม่ใช่อาชีพถาวรหรือเงื่อนไขค่าสกิล ผู้เล่นสามารถตกลงสลับงานและขอให้เพื่อนที่ถนัดช่วยได้

**ทีมสองคน:** รวมงานสำรวจโต๊ะกับบทบาทหนึ่ง และแบ่งควบคุมมินิเกมตามความสมัครใจ  
**เล่นเดี่ยว:** ผู้เล่นเข้าถึงทุกงานตามลำดับ สมุดนักสืบรวบรวมข้อมูลที่พบ ไม่ต้องรอผู้เล่นจำลอง  
**เพื่อนออกระหว่างคดี:** พักคดีหรือให้ผู้เล่นที่เหลือรับงานจำเป็นต่อได้ หลักฐานที่แชร์แล้วและกระดานที่กำลังแก้ต้องยังอยู่ ข้อมูลส่วนตัวที่จำเป็นให้ผู้รับงานเข้าถึงจากจุดสำรวจเดิม ไม่เผยประวัติแชทส่วนตัวแทนเจ้าของ

แชททีมและการ์ดเบาะแสใช้สนับสนุนการพูดคุยในห้องเชิญส่วนตัว ข้อความสำเร็จรูปเป็นตัวเลือก ไม่ใช้แทนการสนทนาทั้งหมด และไม่ต้องเพิ่มแชทสาธารณะในคดีนี้

## 8. ความยาก ความชำนาญ และการสุ่ม

### ความยากรายคน

| มินิเกม | สบาย ๆ | นักสืบ | ท้าทาย |
|---|---|---|---|
| ครอสเวิร์ด | ตารางเล็ก มีภาพและคลังคำ | คำใบ้ข้อความและตัวอักษรบางช่อง | ตารางใหญ่ขึ้นและลดตัวช่วยเริ่มต้น |
| จิ๊กซอว์ | เสนอ 6 ชิ้น พร้อมภาพตัวอย่าง | เสนอ 12 ชิ้น พร้อมดูภาพตัวอย่างได้ | เสนอ 20 ชิ้น โดยคำใบ้เรียกใช้ได้ |
| เลื่อนบล็อก | ตัวอย่างสามจังหวะในหัวข้อ 9 | กระดานที่ผ่านตรวจสอบและใช้หลายจังหวะขึ้น | กระดานซับซ้อนขึ้น แต่ไม่มีการจับเวลา |

ตัวเลขชิ้นภาพและขนาดโจทย์เป็นค่าตั้งต้นสำหรับทดสอบ ต้องตรวจความอ่านง่ายและพื้นที่แตะบนมือถือจริง ความยากเปลี่ยนโจทย์และคำช่วย ไม่เปลี่ยนหลักฐานปลายทาง

ในงานร่วมกัน ใช้กระดานเดียวต่อหนึ่งงาน โดยเริ่มตามระดับของผู้ควบคุม หากโอนงานให้เพื่อนให้คงกระดานและความคืบหน้าไว้ก่อน เพื่อนเปิดคำใบ้เพิ่มได้ การเปลี่ยนเป็นโจทย์ระดับใหม่ต้องยืนยันและแจ้งว่าจะเริ่มเฉพาะมินิเกมนั้นใหม่ ไม่รีเซ็ตทั้งคดี

### ความชำนาญของอวตาร

ครอสเวิร์ดสัมพันธ์กับภาษา จิ๊กซอว์สัมพันธ์กับมิติสัมพันธ์ และเลื่อนบล็อกสัมพันธ์กับตรรกะ ทักษะใหม่ปลดล็อกตามบทฝึกหรือเนื้อเรื่อง ส่วนความชำนาญสะสมจากการเล่น โดยไม่กำหนดคะแนนขั้นต่ำก่อนรับงานหลัก

ตัวช่วยจากสกิลควรเป็นคำใบ้เพิ่มเติม ไม่ใช่คำตอบอัตโนมัติหรือสิทธิ์เฉพาะที่ทำให้คนอื่นเล่นต่อไม่ได้ ค่าทั้งหมดเป็นระบบความก้าวหน้าในเกม ไม่ใช่การประเมินสติปัญญาหรือการกล่าวอ้างผลต่อสุขภาพและความจำของผู้เล่น

### การสุ่มอย่างมีขอบเขต

ร่างนี้แสดงเส้นทางตัวอย่างหนึ่งชุด เริ่มต้นต้นแบบด้วยชุดที่ตรวจสอบแล้วก่อน เมื่อมีคลังโจทย์จึงสุ่มโจทย์ใหม่จากแม่แบบที่ผู้เล่นเคยฝึก โดยต้องเข้ากับวัตถุหรือภารกิจนั้น

สุ่มคำครอสเวิร์ดที่ไม่ใช่หลักฐาน การตัดและวางชิ้นจิ๊กซอว์ หรือกระดานเลื่อนบล็อกที่แก้ได้จริง แต่ทุกชุดต้องนำกลับไปยังข้อเท็จจริงเดิม: **น้ารินย้ายอัลบั้มเข้ากล่องรูปดาวใต้หน้าต่าง**

ไม่เปลี่ยนชนิดเกมกลางงาน ไม่เปลี่ยนคำตอบเมื่อเชื่อมต่อใหม่ และไม่เปลี่ยนตัวล็อกบนกล่องเป็นเกมที่ไม่เข้ากับวัตถุโดยไม่มีฉากรองรับ หากยังไม่เคยฝึกแม่แบบที่จำเป็น ให้เปิดบทแนะนำสั้น ๆ ก่อนงานนั้น

### 9.2 จิ๊กซอว์ — แผนผังเก็บของ

**ภาพต้นฉบับที่ต้องทำ:** ภาพห้องนั่งเล่นแบบง่าย แสดงหน้าต่าง โซฟา และชั้นหนังสือ ใช้รูปภาพถ่ายกับซองจดหมายชี้ไปยังพื้นที่ใต้หน้าต่าง และรูปของเล่นชี้ไปยังข้างโซฟา พร้อมป้ายคำอ่านได้ชัดเจน

ไม่วาดสัญลักษณ์รูปดาวลงบนกล่องในแผนผัง เพื่อให้คำบอกเล่าจากอีกบทบาทยังมีความหมาย เมื่อเล่นเสร็จต้องมีภาพเต็มให้เปิดดูซ้ำและแชร์เป็นการ์ดได้

**กติกาเริ่มต้น:** ชิ้นภาพไม่ต้องหมุน เมื่อวางถูกตำแหน่งให้ดูดเข้าช่อง ทุกระดับให้ผลหลักฐานเดียวกัน

**คำใบ้เพิ่ม:** แสดงขอบภาพ / ไฮไลต์บริเวณที่จะวางชิ้นที่เลือก / วางตัวอย่างหนึ่งชิ้น

```text
.  B  B  .
.  .  .  .
```

`K` คือกุญแจการ์ตูนยาว 2 ช่อง เลื่อนได้แนวนอน  
`A` คือบล็อกยาว 2 ช่อง เลื่อนได้แนวตั้ง  
`B` คือบล็อกยาว 2 ช่อง เลื่อนได้แนวนอน  
`.` คือช่องว่าง

บล็อกเลื่อนได้เฉพาะตามแนวของตัวเองและห้ามทับกัน เมื่อหัวกุญแจถึงช่องขวาสุดของแถวทางออก ให้เล่นภาพกุญแจออกจากรางและจบโจทย์อัตโนมัติ

**เฉลยตัวอย่าง:** เลื่อน `B` ไปซ้าย 1 ช่อง → เลื่อน `A` ลง 2 ช่อง → เลื่อน `K` ไปขวา 2 ช่อง

**คำใบ้เพิ่ม:** ชี้สิ่งที่ขวางกุญแจ / ชี้บล็อกที่ต้องขยับก่อน / แสดงตัวอย่างจังหวะแรก มีปุ่มย้อนกลับและเริ่มโจทย์ใหม่โดยไม่เสียความคืบหน้าของคดี

โจทย์ที่ซับซ้อนกว่านี้ยังต้องสร้างและตรวจสอบเส้นทางแก้ก่อนนำเข้าคลัง ไม่ถือว่ามีครบแล้วจากตัวอย่างเดียว

## 10. ข้อมูลที่ต้องบันทึกและเงื่อนไขจบคดี

**ข้อมูลขั้นต่ำ:** บทฝึกที่ผ่าน งานที่รับ หลักฐานที่แต่ละคนพบและเลือกแชร์ สถานะมินิเกมและกระดานปัจจุบัน ตัวแปรโจทย์ที่สุ่มไว้ ความชำนาญที่ได้รับ และสถานะคดี

**จบคดีเมื่อ:** ทีมระบุกล่องเป้าหมายจากหลักฐาน เปิดกล่องได้ และนำอัลบั้มกลับให้ยายมะลิ จากนั้นบันทึกคดีสำเร็จก่อนเล่นฉากโปสการ์ด งานครอสเวิร์ดเสริมไม่เป็นเงื่อนไขการจบคดี

รางวัลความชำนาญหรือรางวัลจบงานต้องไม่จ่ายซ้ำจากการกดรับพร้อมกันหรือเชื่อมต่อกลับมา การใช้คำใบ้ไม่ทำให้เนื้อเรื่องหายหรือถูกลงโทษ

เมื่อกลับจากมินิเกม ให้ห้องยังแสดงผลการกระทำที่ทำสำเร็จ เช่น แผนผังประกอบแล้ว กล่องเปิดแล้ว และอัลบั้มกลับมาอยู่บนโต๊ะ

## 11. สิ่งที่ต้องเตรียมเพื่อทดลองเล่น

| หมวด | เนื้อหาชุดแรก |
|---|---|
| ฉาก | ห้องนั่งเล่น isometric แนวตั้ง 1 ห้อง และภาพขยายวัตถุสำคัญ |
| ตัวละคร | ยายมะลิ ลุงเมฆ น้าริน และอวตารสำเร็จรูป |
| สิ่งของ | อัลบั้ม ข้อความ รอยน้ำ สมุดครอสเวิร์ด แผนผังจิ๊กซอว์ กล่องสามใบ และโปสการ์ด |
| โจทย์ | บทฝึกของสามแม่แบบ และโจทย์คดีตามระดับที่นำมาทดสอบจริง |
| เนื้อเรื่อง | บทสนทนาตามฉาก การ์ดหลักฐาน ข้อความช่วยคิด และฉากสรุปคดี |
| เสียงเสริม | เสียงแตะ ชิ้นภาพเข้าที่ กล่องเปิด และพลิกหน้าอัลบั้ม ไม่ต้องพึ่งเสียงในการแก้โจทย์ |

**คำถามหลักหลังทดลอง:** ผู้เล่นเข้าใจว่าทำไมต้องรวมหลักฐานหรือไม่ ได้คุยและขอให้เพื่อนช่วยจริงหรือไม่ ครอสเวิร์ดงานเสริมสนุกพอให้เลือกเล่นเองหรือไม่ และพบอัลบั้มแล้วรู้สึกทั้งจบคดีอย่างพอใจและอยากรู้ต่อเรื่องโปสการ์ดหรือไม่

**ขอบเขตร่างนี้:** หนึ่งบทฝึก หนึ่งห้อง หนึ่งคดี มินิเกมสามแม่แบบ และหนึ่งปมส่งต่อ ยังไม่เพิ่มเทศกาล ระบบกิลด์ คอมมูนิตี้ขนาดใหญ่ อาชีพถาวร หรือคดีที่สองที่เล่นได้จริง
