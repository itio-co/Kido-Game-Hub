## 1. จุดประสงค์ / Pitch
โหมด GOD ในเกม สำหรับคนที่ล็อกอินแอดมินแล้ว: ปุ่มในตั้งค่า ไอคอนลอย เมนูไปหน้าแอดมิน และตัวตรวจ JSON ของหน้าปัจจุบัน แยกจากโมดูล `god` ที่เหลือแค่หน้าแอดมินและ API

## 2. แฟนตาซีของผู้เล่น
ไม่มีสำหรับผู้เล่นทั่วไป คนดูแลเห็นฟองลอยเหนือโลกของเกม แบบสัตว์เลี้ยง AI

## 3. Core loop
1. แตะป้ายเวอร์ชันมุมซ้ายบน 8 ครั้งภายใน 3 วินาที หรือเปิดสวิตช์ในตั้งค่า 2. ถ้ามีเซสชันแล้วไอคอนลอยโผล่ทันที ถ้ายังไม่มีให้ใส่รหัสในเกม 3. แตะไอคอนแล้วเลือกแอดมินหรือตรวจข้อมูล

## 4. กฎและ invariants
- ปุ่ม GOD ในตั้งค่ายังโชว์เฉพาะเมื่อ `GET /api/god/me` ผ่าน
- แตะป้ายเวอร์ชัน 8 ครั้งภายใน 3 วินาทีปลดโหมด GOD เกินเวลาแล้วนับใหม่ ครั้งที่ 5–7 มีคำใบ้เล็ก ๆ
- ถ้ามีเซสชันอยู่แล้วไอคอนลอยเปิดทันที ถ้าไม่มีให้ใส่รหัสผ่านในเกม ใช้ `POST /api/god/login` ตาม APP_BASE ไม่เก็บบันทึกรหัส คุกกี้เซสชันยังเป็นของเซิร์ฟเวอร์ รหัสผิดและถูกล็อกแสดงตาม API เดิม
- สวิตช์เปิดปิดและตำแหน่งไอคอนจำในเครื่อง (`nesg.god.float.v1`) คนละอย่างกับคุกกี้ ปิดสวิตช์แล้วไอคอนหาย เซสชันหมดไอคอนหายแม้สวิตช์เคยเปิด
- «แอดมิน» ไปที่ `{APP_BASE}/god` จึงใช้ได้ทั้ง `/never` และ `/dev/never`
- «ตรวจข้อมูล» แสดง JSON ที่พับหัวข้อได้ ของฉาก ฮอตสปอต สถานะคดี เซฟ (รวม `mapUnlocked`) เวอร์ชันโมดูล/กติกา และเลข build ของแอป อัปเดตเมื่อเปลี่ยนฉาก มีปุ่มคัดลอก
- ก่อนแสดงและก่อนคัดลอก ฟิลด์ที่ชื่อหรือค่าเป็นโทเคน รหัสผ่าน คุกกี้ หรือความลับถูกแทนด้วย `[redacted]` ไม่มี `GOD_ADMIN_PASSWORD` และไม่มี player token ในก้อนนั้น

## 5. Input / การควบคุม
แตะป้าย `v0.6.x` มุมซ้ายบน 8 ครั้ง หรือปุ่ม GOD มุมขวาบนของกล่องตั้งค่า ลากไอคอนลอยได้ แตะเพื่อเปิดเมนู «แอดมิน» และ «ตรวจข้อมูล» บนจอแนวตั้ง 390x844

## 6. คะแนนและความยาก
ไม่มี

## 7. Progression
ไม่มี ความชอบไอคอนอยู่แค่ในเครื่องนี้

## 8. Content / config surface
ข้อความอยู่ที่ `src/locales/*.json` คีย์ `god.float.*` เซสชันแอดมินยังเป็นของโมดูล `god`

## 9. UX / หน้าจอ
`GodFloat.svelte` ฟองสีทองเหนือโลกของเกม เมนูเล็กสองปุ่ม แผงตรวจข้อมูลเป็น JSON พับได้ ทับไอคอนขณะเปิด กล่องรหัสผ่านอยู่ในเกมเมื่อแตะป้ายเวอร์ชันครบแต่ยังไม่มีเซสชัน

## 10. Data & telemetry (ฟิลด์บนเซิร์ฟเวอร์)
ไม่เขียนเซิร์ฟเวอร์ เรียก `GET /me` เพื่อตรวจเซสชัน และ `POST /login` เมื่อแตะป้ายเวอร์ชันครบแต่ยังไม่เข้าสู่ระบบ รหัสผ่านไม่ถูกเก็บในเครื่อง

core >=0.6.20, god ^2.0.0
