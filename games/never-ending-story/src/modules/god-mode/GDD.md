|---|---|

## 1. จุดประสงค์ / Pitch
โหมด GOD ในเกม สำหรับคนที่ล็อกอินแอดมินแล้ว หรือผู้เล่นที่มีบทบาท `god` / `super_god`: ปุ่มในตั้งค่า ไอคอนลอย เมนูไปหน้าแอดมิน และตัวตรวจ JSON ของหน้าปัจจุบัน แยกจากโมดูล `god` ที่เหลือแค่หน้าแอดมินและ API

## 2. แฟนตาซีของผู้เล่น
ไม่มีสำหรับผู้เล่นทั่วไป คนดูแลเห็นฟองลอยเหนือโลกของเกม แบบสัตว์เลี้ยง AI

## 3. Core loop
1. แตะป้ายเวอร์ชันมุมซ้ายบน 8 ครั้งภายใน 3 วินาที หรือเปิดสวิตช์ในตั้งค่า 2. ถ้ามีเซสชันแล้วไอคอนลอยโผล่ทันที ถ้ายังไม่มีให้ใส่รหัสในเกม 3. แตะไอคอนแล้วเลือกแอดมิน ตรวจข้อมูล «รายการคำขอ» หรือ «ขอสิ่งที่อยากได้» (Wish)

## 4. กฎและ invariants
- ปุ่ม GOD ในตั้งค่าและไอคอนลอยโชว์เฉพาะเมื่อเซิร์ฟเวอร์ยืนยันสิทธิ์ (`godAccessRole`): ถ้า `GET /api/god/me` ผ่านด้วยคุกกี้แอดมิน ถือเป็น `super_god` มิฉะนั้นถามบทบาทของผู้เล่นเองจาก `GET /api/players/me` (Bearer token ของเครื่อง) นับเฉพาะ `god` และ `super_god` ผู้เล่นบทบาท `player` ไม่เห็นไอคอนเลย แม้จะแก้ค่าในเครื่องเอง เพราะสิทธิ์ที่แท้จริงอยู่ที่เซิร์ฟเวอร์
- ผู้เล่นบทบาท `god` เห็นเมนู «ตรวจข้อมูล» เท่านั้น ปุ่ม «แชร์ลิงก์» ส่ง Bearer ของผู้เล่นไปที่ `POST /api/god/snapshots` เมนู «แอดมิน» แสดงเฉพาะ `super_god` เพราะหน้าแอดมินต้องใช้รหัสผ่าน
- แตะป้ายเวอร์ชันครบ 8 ครั้ง: ถ้ามีสิทธิ์อยู่แล้วเปิดไอคอนทันที ถ้าไม่มีให้ใส่รหัสผ่านแอดมิน (ทางปลดล็อกเดิม ได้สิทธิ์ `super_god` ของเซสชันนั้น)
- แตะป้ายเวอร์ชัน 8 ครั้งภายใน 3 วินาทีปลดโหมด GOD เกินเวลาแล้วนับใหม่ ครั้งที่ 5–7 มีคำใบ้เล็ก ๆ
- ถ้ามีเซสชันอยู่แล้วไอคอนลอยเปิดทันที ถ้าไม่มีให้ใส่รหัสผ่านในเกม ใช้ `POST /api/god/login` ตาม APP_BASE ไม่เก็บบันทึกรหัส คุกกี้เซสชันยังเป็นของเซิร์ฟเวอร์ รหัสผิดและถูกล็อกแสดงตาม API เดิม
- สวิตช์เปิดปิดและตำแหน่งไอคอนจำในเครื่อง (`nesg.god.float.v1`) คนละอย่างกับคุกกี้ ปิดสวิตช์แล้วไอคอนหาย เซสชันหมดไอคอนหายแม้สวิตช์เคยเปิด
- «แอดมิน» ไปที่ `{APP_BASE}/god` จึงใช้ได้ทั้ง `/never` และ `/dev/never`
- «ตรวจข้อมูล» แสดง JSON ที่พับหัวข้อได้ ของฉาก ฮอตสปอต สถานะคดี เซฟ (รวม `mapUnlocked` และ `stateCheck`) เวอร์ชันโมดูล/กติกา และเลข build ของแอป อัปเดตเมื่อเปลี่ยนฉาก ปุ่ม «แชร์ลิงก์» สร้างลิงก์อายุ 1 ชั่วโมง 24 ชั่วโมง (ค่าเริ่มต้น) หรือ 7 วัน
- ก่อนแสดงและก่อนส่งขึ้นเซิร์ฟเวอร์ ฟิลด์ที่ชื่อหรือค่าเป็นโทเคน รหัสผ่าน คุกกี้ หรือความลับถูกแทนด้วย `[redacted]` ไม่มี `GOD_ADMIN_PASSWORD` และไม่มี player token ในก้อนนั้น เซิร์ฟเวอร์กรองซ้ำอีกครั้ง

- **Wish** โชว์ให้ผู้เล่น god / super_god และเซสชันแอดมิน (ซึ่งเป็น super_god) แตะแล้วเมนูและไอคอนถูกซ่อนชั่วขณะ ถ่ายภาพหน้าจอของกรอบโทรศัพท์ (ไม่มีไอคอน GOD ในภาพ) พร้อมเก็บ JSON ตรวจข้อมูลของหน้านั้น (กรองความลับเหมือนปุ่ม «ตรวจข้อมูล») จากนั้นเปิดแผ่นพิมพ์ข้อความ มีภาพย่อ ปุ่มส่ง และปุ่มยกเลิก ส่งแล้วเซิร์ฟเวอร์ประทับเวลา (UTC และวันที่กรุงเทพฯ) สร้างลิงก์ตรวจข้อมูลอายุ 7 วันและเก็บ state ไว้ถาวรในฐานข้อมูล แล้วแสดงข้อความยืนยันพร้อมเวลา ถ้าเบราว์เซอร์ถ่ายภาพไม่ได้ ยังส่งข้อความและข้อมูลได้โดยไม่มีภาพ ถ้าส่งไม่สำเร็จ ข้อความที่พิมพ์ยังอยู่
- **รายการคำขอ** โชว์ให้ผู้เล่น god / super_god และเซสชันแอดมินเช่นกัน เปิดแผงในเกมแสดงคำขอทั้งหมด ใหม่สุดก่อน แต่ละใบมีวันเวลาตามกรุงเทพฯ ข้อความ ภาพย่อ (แตะขยาย) ผู้ส่ง (รหัสผู้เล่น/บทบาท ไม่มีโทเคน) ป้ายใหม่/อ่านแล้ว และลิงก์ตรวจข้อมูล แตะใบเพื่อดูรายละเอียด แบ่งหน้าละ 20 รายการแบบเดียวกับตารางผู้เล่นในแอดมิน ผู้เล่น god ดูได้อย่างเดียว การทำเครื่องหมายว่าอ่านแล้วยังเป็นของ super god เท่านั้น (ใช้ตอนดึงคำขอไปทำ ไม่มีปุ่มนี้ในแผงในเกม)
- ภาพเป็น JPEG ไม่เกิน ~150 KB (ฝั่งเครื่องย่อให้พอดี เซิร์ฟเวอร์รับไม่เกิน 400 KB) ไม่มีโทเคนผู้เล่นหรือรหัสผ่านในภาพรวมถึงใน state ที่ส่ง
- ผู้ส่งต้องมีบทบาท god ขึ้นไปที่เซิร์ฟเวอร์ยืนยัน (เซสชันแอดมินหรือ Bearer) ไม่มีสิทธิ์เซิร์ฟเวอร์ตอบ 401 หรือ 403

## 5. Input / การควบคุม
แตะป้าย `v0.6.x` มุมซ้ายบน 8 ครั้ง หรือปุ่ม GOD มุมขวาบนของกล่องตั้งค่า ลากไอคอนลอยแล้วจุดที่จับอยู่ใต้เมาส์หรือนิ้วตลอด ระยะลากคิดจากกรอบโทรศัพท์ที่มองเห็น ไม่ใช่กรอบฟองเอง ขยับไม่เกินเกณฑ์แตะยังเปิดเมนู «แอดมิน» และ «ตรวจข้อมูล» บนจอแนวตั้ง 390x844

## 7. Progression
ไม่มี ความชอบไอคอนอยู่แค่ในเครื่องนี้

## 8. Content / config surface
ข้อความอยู่ที่ `src/locales/*.json` คีย์ `god.float.*` เซสชันแอดมินยังเป็นของโมดูล `god`

## 9. UX / หน้าจอ
`GodFloat.svelte` ฟองสีทองเหนือโลกของเกม เมนูเล็ก: ผู้เล่น god เห็นตรวจข้อมูล รายการคำขอ และขอสิ่งที่อยากได้ ส่วนแอดมินมีเฉพาะ super_god แผงตรวจข้อมูลเป็น JSON พับได้ `WishSheet.svelte` เป็นแผ่นล่างสำหรับพิมพ์คำขอ แสดงภาพย่อ ปุ่มส่ง/ยกเลิก และข้อความยืนยัน `WishList.svelte` เป็นแผงรายการคำขอในเกม ทับไอคอนขณะเปิด กล่องรหัสผ่านอยู่ในเกมเมื่อแตะป้ายเวอร์ชันครบแต่ยังไม่มีเซสชัน

## 10. Data & telemetry (ฟิลด์บนเซิร์ฟเวอร์)
เรียก `GET /api/god/me` เพื่อตรวจเซสชัน แล้ว `GET /api/players/me` เพื่อถามบทบาทของผู้เล่นเอง และ `POST /login` เมื่อแตะป้ายเวอร์ชันครบแต่ยังไม่เข้าสู่ระบบ รหัสผ่านไม่ถูกเก็บในเครื่อง «แชร์ลิงก์» เรียก `POST /api/god/snapshots` ของโมดูล god ลิงก์ที่ได้เปิดได้โดยไม่ต้องล็อกอินจนกว่าจะหมดอายุ «ขอสิ่งที่อยากได้» เรียก `POST /api/wishes` ครั้งเดียวพร้อมข้อความ ภาพ และ state (`capture.ts` ถ่ายภาพด้วย DOM→SVG→canvas ไม่ใช้ไลบรารี) «รายการคำขอ» เรียก `GET /api/god/wishes?order=desc&limit=20&page=` และดึงภาพด้วย Bearer (ใช้ blob URL เพราะแท็กภาพส่งโทเคนไม่ได้) ส่งทั้งคุกกี้เซสชันและ Bearer ของผู้เล่น รายละเอียดอยู่ใน `docs/god-wish-th.md`
