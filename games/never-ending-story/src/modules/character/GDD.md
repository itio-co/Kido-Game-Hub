## 1. จุดประสงค์ / Pitch
ทะเบียนคนที่มีอยู่แล้วในเกม: ชื่อ บทบาท รูปอ้างอิง และพรอมต์สร้างภาพภาษาอังกฤษ

## 2. แฟนตาซีของผู้เล่น
ผู้เล่นเจอคนเดิมทุกฉาก ย่ามะลิผมสั้นสีเงินปล่อยหลวม ไม่มวย

## 3. Core loop
1. โมดูลอื่นเรียก `character(id)` หรือ `portraitFile(id)` จาก public entry
2. ชื่อมาจากคีย์ `character.*.name` ใน locales
3. หน้า god แท็บคลังแสดงรูป พรอมต์ และปุ่มคัดลอก

## 4. กฎและ invariants
- มีหกคนที่ปรากฏจริง: `player` หนู, `grandma` ย่ามะลิ, `mom` แม่, `uncle-mek` ลุงเมฆ, `aunt-rin` น้าริน, `grandpa-young` ตาตอนหนุ่ม
- ไม่มีตัวละครชื่อเพื่อนบีในโค้ดหรือภาพปัจจุบัน จึงไม่ใส่
- ย่าห้ามมวยผมและห้ามรวบจุก พรอมต์และเนกาทีฟเขียนไว้ตรงๆ
- ไฟล์รูปยังอยู่ `public/img/` เส้นทางเดิม เกมโหลดด้วย `imageUrl`
- พรอมต์ทั้งหมด `promptSource: reconstructed` ไม่พบพรอมต์เจนรูปต้นฉบับใน repo โน้ตใน `assets.json` ใช้เป็นคำอธิบายหน้าตา ไม่ใช่พรอมต์
