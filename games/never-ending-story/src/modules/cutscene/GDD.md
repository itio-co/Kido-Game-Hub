# GDD: Cut Scene (`cutscene`)

| ฟิลด์ | ค่า |
|---|---|
| kind | cutscene |
| เวอร์ชัน | 1.0.0 |
| เทมเพลต | `docs/gdd/TEMPLATE.md` |
| อ้างอิง | `public/data/case-flow.json`, `src/lib/prologue.ts` |

## 1. จุดประสงค์ / Pitch
ทะเบียนภาพฉากที่ใช้จริง: โปรล็อก เปิดเรื่องและจบคดี 01 และภาพห้อง พร้อมพรอมต์สร้างภาพ คนในเฟรมอ้างรหัสจากโมดูล `character`

## 2. แฟนตาซีของผู้เล่น
ภาพบ้านย่าและฉากครอบครัวคงสไตล์ low-poly เดิม

## 3. Core loop
1. `artworkFile(id)` คืนชื่อไฟล์ใต้ `public/img/` เส้นเดิม
2. `filesForUse('event-01')` คือรายการที่ `event-01` ส่งออกเป็น `EVENT_IMAGES`
3. โปรล็อกเลือกห้าเฟรมจากรหัส `prologue.*`
4. หน้า god แท็บคลังแสดงภาพ พรอมต์ และตัวละครในเฟรม

## 4. กฎและ invariants
- ไฟล์ไม่ถูกย้าย เพื่อให้สตอรีแพ็กและ `imageUrl` ใช้ชื่อเดิม
- คนในภาพเป็น `characterIds` ไม่ก็อปชีตตัวละครทั้งก้อน ย่าในพรอมต์ยังระบุผมสั้นปล่อยหลวม
- พรอมต์ทุกใบเป็น `reconstructed` ไม่พบพรอมต์เจนรูปของฉากเหล่านี้ใน repo (พรอมต์ตู้ข้างเตียงเป็นงาน 3 มิติคนละชิ้น)
- ภาพกระทะผัดกับย่าไม่ได้อยู่โมดูลนี้ เป็นศิลป์ของแพ็ก stirfry

## 5. Input / การควบคุม
เลื่อนการ์ดบน god แล้วคัดลอกพรอมต์

## 6. คะแนนและความยาก
ไม่มี จิ๊กซอว์ยังใช้ `house-map.jpg` ใบเดิมผ่าน `artworkFile('prologue.house-map')`

## 7. Progression
ไม่มี

## 8. Content / config surface
เพิ่มเฟรมใน `registry.ts`: `id`, `file`, `usedIn`, `characterIds`, `prompt`, `negative`, `styleNotes`, `order` ถ้าเป็นภาพที่ `event-01` ต้องส่งออก ให้ใส่ `event-01` ใน `usedIn` และเรียง `order`

## 9. UX / หน้าจอ
กลุ่ม `คัตซีน` ใน `/never/god#/modules` และแท็บคลังของ `#/modules/cutscene`

## 10. Data & telemetry (ฟิลด์บนเซิร์ฟเวอร์)
ไม่มี ชื่อไฟล์ใน `case-flow.json` ยังเป็นสตริงเดิม

## 11. Dependencies + เวอร์ชัน
core >=0.6.13, character ^1.0.0 ผู้ใช้: โปรล็อก, event-01, event-core, โหมด challenge (จิ๊กซอว์แผนผัง)

## 12. คำถามที่ยังเปิดอยู่ / Backlog
- **[backlog]** ให้สตอรีแพ็กอ้าง `id` แทนชื่อไฟล์
- **[backlog]** ภาพแปรตามเวลาที่ยังไม่มีไฟล์
- **[backlog]** เก็บพรอมต์ต้นฉบับถ้าทีมศิลป์ส่งไฟล์พรอมต์มาทีหลัง
