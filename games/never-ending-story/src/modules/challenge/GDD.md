## 1. จุดประสงค์ / Pitch
ทำให้มินิเกมเล่นซ้ำได้แบบมีคะแนน ท้าเพื่อนผ่านลิงก์ และขึ้นกระดานคะแนนออนไลน์

## 2. แฟนตาซีของผู้เล่น
แข่งกับเพื่อนในปริศนาชุดเดียวกัน

## 3. Core loop
1. เลือกเกม+ระดับ (seed) 2. เล่น 3. ได้คะแนน 4. แชร์ลิงก์ `#/challenge/<game>/<diff>/<seed>/<ruleset>` เช่น `challenge@1.1.0+crossword@1.0.0` 5. ส่งคะแนนออนไลน์พร้อม `ruleset`

## 4. กฎและ invariants
- seed เดียวกัน = ปริศนาเดียวกัน
- คะแนนสูงชนะ เท่ากันเวลาน้อยชนะ (`compare`)
- run token = protobuf + แท็ก SHA-256 6 ไบต์ (`runProto.ts`) ตรวจที่ Worker

## 5. Input / การควบคุม
ปุ่มเริ่ม แชร์ ดูกระดาน

จิ๊กซอว์ใช้กระดานลาก-หมุนชุดเดียวกับโหมดอีเวนต์: ลากชิ้นอิสระ จุดกึ่งกลางชิ้นไม่หลุดขอบกระดาน ระดับปานกลางแตะชิ้นเพื่อหมุน 90° โดยไม่มีไอคอนหมุน ระดับยากบนมือถือหมุนด้วยสองนิ้ว และบนเว็บกดเมาส์ขวาค้างแล้วหมุนไปทางเมาส์ (ไม่เปิดเมนูคลิกขวา) คำใบ้วางชิ้นหนึ่งเข้าช่อง

## 6. คะแนนและความยาก
`scoreFor()` อ่าน `ruleset.json` คีย์ 1.1.0 (`correct` 100, `combo` 20, `mistake` 40, `hint` 150, `timeBonus` 10, `mult`, `par`) · ระดับ easy/medium/hard · จำนวนคำ/กริด/จำนวนสลับของแต่ละเกมอยู่ใน ruleset ของมินิเกมนั้น ไม่ได้อยู่ในไฟล์นี้

## 7. Progression
คะแนนดีสุดต่อเกม/ระดับในเครื่องที่คีย์ `nesg.minigame-best.v1` แบบ `chal-cross:easy` / `chal-jig:medium` / `chal-slide:hard` (แยกจากสถิติมินิเกมในคดีซึ่งใช้คีย์ `cross:` `jig:` `slide:`) คะแนนที่มากกว่าถือว่าดีกว่า รอบแรกของระดับนั้นนับเป็นสถิติใหม่ ดาวในไดอะล็อกผลชนะมาจากจำนวนคำใบ้ (0 = 3 ดาว, 1 = 2 ดาว, 2 ขึ้นไป = 1 ดาว) · อันดับออนไลน์ยังแยกตามกติกา

## 8. Content / config surface
`ruleset.json`, รายชื่อเกมบนกระดาน (`BOARD_GAMES` ใน `LeaderboardView`) รวม pack ของ rhythm (`stirfry`) · ป้ายกระดานแสดงกติกาที่กำลังดู

## 9. UX / หน้าจอ
ChallengeView, LeaderboardView (แท็บเกม; stirfry ใช้ระดับ easy/normal/hard) · แบนเนอร์แสดงกติกา · ลิงก์ที่อ้างเวอร์ชันที่ไม่มีใน registry ขึ้นข้อความแล้วให้เล่นกติกาปัจจุบัน · เมื่อเล่นจบขึ้นไดอะล็อกผลชนะร่วม (`WinResultDialog`): ดาว คะแนนเทียบสถิติดีที่สุดของเกมและระดับนั้น เวลา จำนวนคำใบ้ ปุ่มเล่นอีกครั้งและปิด พร้อมผลเทียบเพื่อน ปุ่มแชร์ สุ่มโจทย์ใหม่ และกระดานคะแนน · จิ๊กซอว์ใช้ `JigsawBoard` เต็มพื้นที่เล่นด้านล่าง แถบสั้นบอกจำนวนชิ้นและวิธีหมุนตามระดับ

## 10. Data & telemetry (ฟิลด์บนเซิร์ฟเวอร์)
`POST /never/api/runs`: sessionId, playerId, game, difficulty, seed, score, timeMs, version, **ruleset**, ts, verified, integrity_ok · `GET` leaderboard ต่อ game + difficulty + ruleset (เวอร์ชันแอปไม่แยกกระดาน) · ruleset ว่างในโทเคนเก่า = กติกา 0.6.10

## 11. Dependencies + เวอร์ชัน
minigame-core ^1.3.0 (ลิงก์, เฟสจบรอบ, โทเคน, เปลือกกติกา, ไดอะล็อกผลชนะและสถิติคะแนนต่อระดับ), core, crossword, jigsaw ^1.1.1, slide

โหมด challenge ไม่ถูกยุบเข้า minigame-core เพราะกระดานปริศนาและสูตรคะแนนเป็นของฟีเจอร์นี้ rhythm ไม่ควรต้องดึง crossword มาด้วย
