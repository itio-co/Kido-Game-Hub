## 1. จุดประสงค์ / Pitch
เฟรมเวิร์กของทุกคดี: เปิด story pack, ฉากตัด, แผนผังบ้าน, สมุดคดี, HUD ของเหตุการณ์, มินิเกมในคดี และเอกสารความคืบหน้าที่ขึ้น D1

## 2. แฟนตาซีของผู้เล่น
หลานเดินในบ้านย่า เก็บหลักฐาน เปิดสมุดคดี แล้วเล่นมินิเกมที่ติดอยู่ในฉาก เนื้อเรื่องมาจากแพ็กอย่าง event-01

## 3. Core loop
1. `loadFlow` โหลด `screens.json` + `case-flow.json`
2. `createFlow` จำหน้าจอ หลักฐาน เวลา และด่านฝึก
3. `FlowView` วาดฉาก ฮอตสปอต ตัดฉาก (`ComicPanel`) แผนที่ด่าน และสมุดคดี
4. `primaryEventId` คือเหตุการณ์ที่ไม่มี `unlockAfter` ฉากจบคือ `endingIdFor`
5. `eventProgressBody` สร้างก้อนที่ `cloudSync` ส่ง `PUT /players/me/events/:id`

## 4. กฎและ invariants
- โค้ดเฟรมเวิร์กไม่ฝังบทคดี ข้อความที่ยังฝังใน `FlowView` / `Minigames` เป็นสำเนาเดิมของ UI ก่อนแยกโมดูล
- เหตุการณ์แรกในข้อมูลปัจจุบันคือ `case-01` ฉากจบ `case-01-ending` เหมือนเดิม
- สมุดคดีโชว์เมื่อ `showCaseUi` (context เป็น event และไม่ใช่โหมดฝึก)
- จำนวนหลักฐานคือรายการใน story pack ไม่ใช่เลขตายตัว 5 รหัสที่ไม่อยู่ในรายการ (เช่น E05 เดิม) ไม่ถูกนับ สรุปคดีเปิดเมื่อเก็บครบทุกรหัสในรายการ
- กระเป๋าเก็บรหัสไอเท็มในเซฟ (`bag`) กุญแจคดี (`case-key`) ได้เมื่อสรุปคดีสำเร็จและกล่องยังไม่เปิด เปิดกล่องแล้วกุญแจถูกใช้ และได้รูปปู่ตอนหนุ่ม (`album-photo`) จากอัลบั้มในกล่อง โปสเตอร์อยู่ในรูปชุดเดียวกัน ไม่ใช่ของอีกชิ้น เอารูปให้ย่าแล้วรูปออกจากกระเป๋าและเข้าบทชนะ เซฟที่กล่องเปิดแล้วยังไม่มีรูปและยังไม่ให้ย่าดู จะได้รูปตอนเปิดเกม กระเป๋าใช้โมดูล `item-box` แสดงเป็นช่องไอคอน แตะไอคอนแล้วเปิดรายละเอียด ปิดรายละเอียดแล้วยังอยู่ในกระเป๋า ของที่เพิ่งได้ถูกไฮไลต์สั้น ๆ
- บทย่าเปลี่ยนตามขั้น: ยังสืบ → เปิดเรื่อง, สรุปแล้วแต่กล่องยังปิด → ให้ใช้กุญแจ, กล่องเปิดแล้วและรูปยังอยู่ในกระเป๋า → ขอดูรูปและมีทางเลือกให้ย่าดู, ให้ย่าดูแล้วหรือจบคดี → บทชนะ บทที่ค้างคนละขั้นถูกปรับตอนเปิดเกม
- ปุ่มแผนผังบ้านยังอ่านหลักฐานของจิ๊กซอว์ ไม่ใช่แฟล็กในเซฟ ผู้เล่นที่มี E04 ปุ่มเปิด ผู้ที่แฟล็กเปิดแต่ไม่มี E04 ถูกปิดตอนเปิดเกม
- ตัวตรวจเซฟรายงานข้อที่ซ่อมและข้อที่ยังผิดใน God Inspect (`stateCheck`)
- ปุ่มแผนผังบ้านเป็นปุ่มเดียวในแถบล่าง ใช้เงื่อนไขเดียวกันทุกฉากที่ตั้ง `map` (ห้องนั่งเล่น ห้องทำงาน ครัว ครัวมุมใกล้ โต๊ะ ถาดชิ้นแผนผัง ย่า ลุงเมฆ กล่องดาว) ฉากที่ไม่มี `map` ไม่โชว์ปุ่มนี้
- รหัสปลดล็อกมาจาก `unlocksHouseMap` ของจิ๊กซอว์ หรือจากเกตที่แพ็กคดีลงทะเบียน (คดี 1 คือ E04 แม้ไฟล์เรื่องที่โหลดมาจะไม่มีฟิลด์นี้) ก่อนมีรหัสนั้น ปุ่มยังโชว์พร้อมเครื่องหมายกุญแจ แต่แตะแล้วไม่เปิดแผนผัง ขึ้นข้อความว่าต้องต่อแผนผังให้เสร็จก่อน การเคยจบคดีแล้วไม่ข้ามเกตนี้ การเข้าชมฉาก หลักฐานใบอื่น หรือแฟล็ก `mapUnlocked: true` ที่ไม่มีรหัสนี้ ไม่ปลดล็อก ชนะจิ๊กซอว์ครั้งแรกแล้วขึ้นข้อความสั้น ๆ เซฟที่มีรหัสนั้นปุ่มเปิดอยู่ แฟล็กที่บอกว่าเปิดทั้งที่ไม่มีรหัสถูกเขียนกลับเป็นปิดตอนเปิดเกม แพ็กที่ไม่ได้ตั้งเกตและไม่ได้ลงทะเบียน ปุ่มยังโชว์เหมือนเดิม
- คำถาม "เก็บไว้ที่ไหน" แบบแตะแผนผังใช้โซนตามแผนผังบ้าน v2 (ทางเข้าด้านบน): ห้องนั่งเล่น บน 12–56%, ห้องซ้ายล่าง (`study`) และครัวขวาล่าง 57–88% ถ้าวาดแผนผังใหม่ต้องปรับโซนตาม
- ข้อความได้หลักฐานหรือปลดล็อกพลังย้อนเวลาแสดงด้านล่างตำแหน่งเดียวกับกล่องบทพูด หลังผู้เล่นแตะปิดบทหรือปิดโน้ตแล้ว ไม่ขึ้นพร้อมกันและไม่ขึ้นด้านบน
- พลังย้อนชั่วโมงโชว์ที่นาฬิกาเมื่อผู้เล่นมีเบาะแสที่ปลดล็อกช่องเวลาบ่ายนี้แล้วเท่านั้น ก่อนหน้านั้นแตะนาฬิกาแล้วไม่เปิดแผงพลัง แค่บอกสั้น ๆ ว่าต้องมีเบาะแสก่อน แผงนาฬิกาแสดงเฉพาะช่องที่ปลดล็อกแล้ว ไม่โชว์ข้อความ ??? หรือคำใบ้เอง คำใบ้มีเมื่อผู้เล่นกดใช้แล้วช่องนั้นยังล็อก ย้อนวันด้วยปฏิทินเป็นพลังคนละอย่าง เริ่มต้นยังใช้ไม่ได้ เปิดปฏิทินดูวันที่ได้ แต่ปุ่มย้อนวันบอกว่าพลังยังไม่พอ ใช้ได้แค่นาฬิกา
- `playMode` คืน practice / story / challenge ตาม context ไม่เปลี่ยนเส้นทางหน้าจอ
- ถ้ากำลังเล่นเหตุการณ์อยู่ (context เป็น event และคดียังไม่จบในรอบนี้) การออกไปหน้าฮับ (ห้องผู้เล่น เลือกเหตุการณ์ มุมฝึก) ทุกทาง ไม่ว่าจะปัดจอ ปุ่มย้อน หรือปุ่มย้อนของเบราว์เซอร์ ต้องถามยืนยันก่อน เพราะการออกจะรีเซ็ตรอบนั้น ถ้าไม่ยืนยัน ให้คงสถานะไว้และกลับมาที่เหตุการณ์ที่เล่นค้างไว้ทันที (รวมตำแหน่งเลื่อนจอ) ถ้าเปิดเกมใหม่ขณะที่เหตุการณ์ยังไม่จบ ให้กลับไปหน้าเดิมที่ค้างไว้ ไม่ถามเมื่อไม่มีเหตุการณ์ที่กำลังเล่น หรือเมื่อคดีในรอบนี้จบแล้ว รวมทางออกจากฉากจบที่ตั้งใจจบรอบ

## 5. Input / การควบคุม
แตะฮอตสปอต เลือกบทพูด พลิกหน้าการ์ตูน (แตะหรือปัดซ้าย = หน้าถัดไป ปัดขวา = ย้อนหน้า ไม่มีปุ่มก่อนหน้า จุดด้านล่างบอกหน้า) ปุ่มย้อน สมุดคดี ปุ่มแผนผังบ้าน (ล็อกอยู่แตะแล้วขึ้นข้อความ ไม่เปิดแผนที่ จนกว่าเกตหลักฐานจะปลดล็อกในรอบนี้) ด่านฝึก บนจอแนวตั้ง ปัดขวาหรือกดย้อนจนจะหลุดจากเหตุการณ์ที่ยังเล่นอยู่ ต้องยืนยันก่อนออก

## 6. คะแนนและความยาก
มินิเกมในคดีใช้ดาวจากจำนวนคำใบ้ (`starCount`) ไม่ส่งกระดานออนไลน์ ระดับความยากเลือกในฉาก difficulty ของแพ็ก

## 7. Progression
หลักฐาน, ไขคดี, โปสเตอร์, ด่านฝึก เก็บในเซฟเดิม (`flow` ใน `nesg.player.v1`)

## 8. Content / config surface
story pack JSON รูปใน `public/img/` แพ็ก event-01 กำหนด `EVENT_ID`

## 9. UX / หน้าจอ
`FlowView` รวมแผนผังบ้าน ห้อง สมุดคดี กระดานคดี ฉากจบ และ `Minigames` (crossword, jigsaw, slide)

เมื่อเคยจบคดีแล้ว ปุ่มข้ามเรื่องเปิด (`skipCutscene`) ไปหน้าเลือกระดับความยากทันที ปุ่มข้ามตอนจบกลับห้องของฉัน แตะปุ่มแล้วขึ้นกล่อง `LoadingDialog` (สไตล์เดียวกับกล่องยืนยันออกจากเหตุการณ์) ทับจอทันที กันกดซ้ำ จนกว่าฉากถัดไปพร้อม ช่วงนี้ข้ามเฟด 300ms ของ `go()` เพื่อไม่ให้จอดำเงียบ ๆ `createFlow().runWithLoading` ใช้กับทรานซิชันช้าอื่นได้เหมือนกัน ข้อความใน `loading.title` / `loading.body`

เมื่อมินิเกมในคดีหรือด่านฝึกจบ จะขึ้น `WinResultDialog` จาก minigame-core ก่อนไปโฟลว์เดิม: ชื่อ เยี่ยมมาก! / เล่นชนะแล้ว ระดับความยาก ดาว เวลาจริงเทียบสถิติดีที่สุดของระดับนั้น ป้ายสถิติใหม่ และจำนวนคำใบ้ กด ต่อไป แล้วค่อยได้หลักฐานหรือกลับไปที่คดี แถบหัวมินิเกมโชว์เวลาจริงและสถิติของระดับที่กำลังเล่นเท่านั้น ไม่ปะปนกับระดับอื่น

## 10. Data & telemetry (ฟิลด์บนเซิร์ฟเวอร์)
`eventProgressBody` ให้ `{ status, progress: { evidence, solved, deduced, reward, posterShown, endingSeen, seen, mapUnlocked } }` ตาราง `player_events` ไม่เปลี่ยน `mapUnlocked` เป็นจริงเมื่อเซฟมีหลักฐานที่จิ๊กซอว์ใช้ปลดปุ่ม

## 11. Dependencies + เวอร์ชัน
core >=0.6.24, minigame-core ^1.1.0, crossword, jigsaw, slide ^1.0.0, stirfry ^1.1.0 (สมุดคดีอ่านสถิติผัด)

## 12. คำถามที่ยังเปิดอยู่ / Backlog
- **[backlog]** ย้ายข้อความไทยที่ยังฝังใน FlowView เข้า locales
- **[backlog]** ให้แพ็กเหตุการณ์ถัดไปลงทะเบียนโดยไม่แก้เฟรมเวิร์ก
