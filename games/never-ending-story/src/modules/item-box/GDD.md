## 1. จุดประสงค์ / Pitch
UI กระเป๋า/คลังของที่ใช้ซ้ำได้ แสดงเป็นช่องไอคอน แตะแล้วเปิดรายละเอียด ปิดรายละเอียดแล้วยังอยู่ในกล่อง

## 2. แฟนตาซีของผู้เล่น
เปิดกระเป๋าแล้วเห็นของเป็นชิ้น ๆ หยิบดูได้ทีละชิ้น

## 3. Core loop
1. เปิดกล่อง เห็นตารางช่องไอคอน (ของที่มีอยู่และช่องว่าง)
2. แตะไอคอน เปิดหน้ารายละเอียด (ภาพจริง ชื่อเฉพาะ และคำอธิบาย)
3. ปิดรายละเอียดกลับไปที่ตาราง หรือปิดกล่องทั้งใบ

## 4. กฎและ invariants
- เปิดกล่องแล้วเห็นไอคอนของชนิดพร้อมชื่อเฉพาะของชิ้นนั้น ไม่โชว์คำอธิบายยาวในช่อง
- ช่องว่างแสดงเป็นกรอบว่าง จำนวนช่องเริ่มต้น 6
- ของที่เพิ่งได้ไฮไลต์สั้น ๆ ตาม `freshId`
- ตัวอักษรในรายละเอียดใช้ขนาดอ่านง่าย (`--fs` ขึ้นไป) เป้าแตะอย่างน้อย 44px
- ไม่รู้จักรหัสในเซฟยังแสดงช่องได้ จะไม่ทำให้เกมพัง
- ปิดรายละเอียดไม่ปิดกระเป๋า

## 5. Input / การควบคุม
แตะไอคอนเพื่อดูรายละเอียด ปุ่มปิดรายละเอียด (`item-detail-close`) กลับไปตาราง ปุ่มปิดกล่อง (`item-box-close`) ปิดทั้ง overlay บนจอแนวตั้ง 390x844 เป็นหลัก

## 6. คะแนนและความยาก
โมดูลนี้ไม่มีคะแนน

## 7. Progression
ไม่เก็บความคืบหน้าเอง รายการของมาจากผู้เรียก (เช่น `session.bag`)

## 8. Content / config surface
ไอคอนช่องมาจากชนิดในโมดูล `item` ชื่อเฉพาะและภาพรายละเอียดมาจากชิ้นไอเทมที่แพ็กเรื่องลงทะเบียนแล้ว ข้อความหัวข้อ ปิด และกระเป๋าว่างมาจากผู้เรียก (locales ของแอป)

## 9. UX / หน้าจอ
แผ่นกระเป๋าหัวสีน้ำตาลเหมือนเดิม ด้านในเป็นตารางช่องไอคอนขอบสีฟ้าแบบ HUD แต่ละช่องแสดงไอคอนชนิดและชื่อเฉพาะ ของที่เพิ่งได้มีแอนิเมชันสั้น ๆ

## 10. Data & telemetry (ฟิลด์บนเซิร์ฟเวอร์)
ไม่ส่งข้อมูลขึ้นเซิร์ฟเวอร์เอง

## 11. Dependencies + เวอร์ชัน
`core >= 0.6.37`, `item ^1.0.0`

## 12. คำถามที่ยังเปิดอยู่ / Backlog
- **[backlog]** ใช้กล่องนี้กับคลังของในห้องผู้เล่นได้หรือไม่
