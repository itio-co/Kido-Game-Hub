# packages/

Code and tooling shared by more than one game. Each package is an npm workspace (`packages/*` in the root `package.json`).

| Package | Path |
|---|---|
| `@itio/mesh-editor` | [`mesh-editor/`](mesh-editor/) |

Adding a package here, or changing a shared script, command, tool, i18n convention, or shared asset, has to be coordinated with the repo organizer, **Kido Game Hub**, first. A game-only helper stays inside that game's folder under `games/`.
